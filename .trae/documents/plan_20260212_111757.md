# Sprint 2: 订单管理模块实施计划

## 一、后端开发任务

### 1. 数据模型层
- 创建 `app/models/order.py` - 订单模型(Order)和订单分类模型(OrderCategory)
- 更新 `app/models/__init__.py` - 导出新模型

### 2. 数据模式层
- 创建 `app/schemas/order.py` - 订单相关的Pydantic模型
  - OrderCreate, OrderUpdate, OrderResponse
  - OrderCategoryCreate, OrderCategoryUpdate, OrderCategoryResponse
  - OrderListResponse (分页响应)

### 3. 服务层
- 创建 `app/services/order_service.py` - 订单业务逻辑
  - create_order, get_order, list_orders, update_order
  - delete_order (软删除), restore_order, get_deleted_orders
- 创建 `app/services/order_category_service.py` - 订单分类业务逻辑
  - create_category, get_category, list_categories
  - update_category, delete_category

### 4. API路由层
- 创建 `app/api/v1/orders.py` - 订单API接口
  - POST /orders - 创建订单
  - GET /orders - 获取订单列表(支持筛选分页)
  - GET /orders/{id} - 获取订单详情
  - PUT /orders/{id} - 更新订单
  - DELETE /orders/{id} - 删除订单(软删除)
  - GET /orders/recycle - 获取回收站订单
  - POST /orders/{id}/restore - 恢复订单
- 创建 `app/api/v1/order_categories.py` - 订单分类API接口
  - POST /categories - 创建分类
  - GET /categories - 获取分类列表
  - GET /categories/{id} - 获取分类详情
  - PUT /categories/{id} - 更新分类
  - DELETE /categories/{id} - 删除分类
- 更新 `app/api/v1/__init__.py` - 注册新路由

### 5. 数据库迁移
- 创建Alembic迁移脚本 - 创建orders和order_categories表

## 五、验收标准

1. 订单记录功能：支持快速记录订单，必填信息验证有效
2. 订单查看功能：支持查看订单列表，支持按日期、类型、标签筛选，支持分页加载
3. 订单编辑功能：支持修改订单信息，订单列表实时更新
4. 订单删除功能：支持删除订单，删除后进入回收站，支持从回收站恢复
5. 订单分类管理功能：支持自定义订单分类，支持编辑和删除
6. 订单标签管理功能：支持自定义订单标签，支持编辑和删除
