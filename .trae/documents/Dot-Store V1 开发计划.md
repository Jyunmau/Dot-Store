# Dot-Store V1 开发计划

## 1. 项目初始化

### 1.1 目录结构搭建
- 创建推荐的目录结构：`apps/api-server`、`modules`、`shared`
- 初始化后端项目：FastAPI + SQLAlchemy + Alembic
- 初始化前端项目：React + Vite
- 配置项目依赖和环境变量

### 1.2 数据库配置
- 创建 PostgreSQL 数据库
- 配置 Alembic 数据迁移
- 初始化核心表结构

## 2. 后端开发

### 2.1 核心模块实现

#### 2.1.1 Event 模块
- 实现 Event 模型和服务
- 支持事件的创建和查询
- 与 Order、Ledger 模块的集成

#### 2.1.2 Order 模块
- 实现 Order 模型、服务和控制器
- 支持订单的创建、更新和查询
- 自动生成审计日志
- 集成 Event 模块

#### 2.1.3 Ledger 模块
- 实现 Ledger 模型、服务和控制器
- 支持账务分录的创建和查询
- 实现分类账管理
- 集成 Event 模块

#### 2.1.4 Report 模块
- 实现 Report 服务
- 支持今日盈亏、收入结构、成本结构等报表
- 只读模式，不直接修改数据

#### 2.1.5 Audit 模块
- 实现 Audit 服务
- 自动记录数据修改历史
- 支持修改记录的查询

#### 2.1.6 Config 模块
- 实现 Config 模型和服务
- 支持分类账定义、常用标签、基础业务类型的配置

### 2.2 API 实现
- 实现 RESTful API 接口
- 支持请求参数校验和错误处理
- 实现 API 文档（Swagger）

## 3. 前端开发

### 3.1 页面组件实现

#### 3.1.1 今日页面
- 显示今日日期和快速切换
- 显示今日收入、支出、盈亏
- 显示今日记录列表
- 提供快捷操作按钮：记一笔、调整账目

#### 3.1.2 记录页面
- 新记录按钮
- 记录筛选功能：按日期、标签、状态
- 记录列表显示：时间、标签、备注摘要、状态
- 记录创建和编辑表单

#### 3.1.3 账本页面
- 时间周期选择
- 分类账列表：收入类、支出类、调整类
- 明细区：时间、金额、来源、关联记录
- 手工调整功能

#### 3.1.4 报表页面
- 时间范围选择：7天、30天、自定义
- 核心指标：总收入、总支出、净利润
- 盈亏变化趋势图
- 分类分析：按标签/类型

#### 3.1.5 设置页面
- 基础信息配置：店铺名称、营业类型
- 标签管理：自定义标签、启用/停用
- 显示配置：估算提示、未补全记录提示

### 3.2 状态管理和API集成
- 使用 React Hooks 和 Context 管理状态
- 实现 API 调用和数据处理
- 实现错误处理和加载状态

## 10. 技术要点

- 模块化单体架构，保持模块间的解耦
- 接受真实世界的不完美，允许数据不完整
- 支持手工修正和审计追踪
- 优先实现核心功能，避免过度设计
- 保持代码的可读性和可维护性
