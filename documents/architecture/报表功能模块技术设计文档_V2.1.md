# 报表功能模块技术设计文档

## 1. 模块概述

报表功能模块是 Dot-Store V2.1 系统的核心业务模块之一，负责提供今日、本周、本月的财务报表，支持报表导出和筛选功能。该模块为用户提供实时的经营状况分析工具。

### 1.1 功能范围

- 基础报表（今日、本周、本月）
- 报表导出（Excel、PDF格式）
- 报表筛选（按日期范围、类型、分类、标签）
- 报表明细查看（按分类、标签查看明细）
- 收支汇总统计（总收入、总支出、净盈亏）

### 1.2 技术栈

- 后端：FastAPI + PostgreSQL + SQLAlchemy + pandas（数据处理）
- 前端：React + TypeScript + Recharts（图表库） + React Query（数据获取） + Zustand（状态管理）
- 数据存储：PostgreSQL 数据库
- 导出工具：OpenPyXL（Excel导出）、WeasyPrint（PDF导出）
- 缓存：Redis（热点数据缓存）

## 3. 数据设计

### 3.1 数据模型

报表模块不直接存储数据，而是基于以下表的数据进行统计分析：

- `transactions` 表：收支记录数据
- `orders` 表：订单数据
- `order_categories` 表：订单分类数据
- `transaction_categories` 表：收支分类数据

### 3.2 数据关系

报表模块通过以下关系进行数据统计：

- 收支记录与用户的关系：按用户ID筛选数据
- 收支记录与分类的关系：按分类统计金额
- 订单与收支记录的关系：关联订单的收入统计
- 时间维度关系：按日期、周、月统计数据

### 3.3 存储方案

- 报表数据实时计算，不存储历史报表
- 导出的报表文件临时生成，通过HTTP响应返回给前端
- 考虑使用 Redis 缓存热点报表数据，如当日报表

      localStorage.removeItem('token');
      window.location.href = '/login';
    }
    return Promise.reject(error.response?.data || error.message);
  }

import api from './api';
import { ReportData, ReportFilters, CategoryAnalysis } from '../types/report';

export const reportApi = {
  // 获取每日报表
  getDailyReport: async (date: string): Promise<ReportData> => {
    const response = await api.get('/reports/daily', {
      params: { date }
    });
    return response.data;
  },
  
  // 获取每周报表
  getWeeklyReport: async (startDate: string, endDate: string): Promise<ReportData> => {
    const response = await api.get('/reports/weekly', {
      params: { start_date: startDate, end_date: endDate }
    });
    return response.data;
  },
  
  // 获取每月报表
  getMonthlyReport: async (year: number, month: number): Promise<ReportData> => {
    const response = await api.get('/reports/monthly', {
      params: { year, month }
    });
    return response.data;
  },
  
  // 获取自定义报表
  getCustomReport: async (filters: ReportFilters): Promise<ReportData> => {
    const response = await api.post('/reports/custom', filters);
    return response.data;
  },
  
  // 导出报表
  exportReport: async (reportData: ReportData, format: string): Promise<Blob> => {
    const response = await api.post(`/reports/export/${format}`, 
      { report_data: reportData, format },
      {
        responseType: 'blob'
      }
    );
    return response;
  },
  
  // 获取分类分析
  getCategoryAnalysis: async (startDate: string, endDate: string, type: string): Promise<CategoryAnalysis> => {
    const response = await api.get('/reports/category-analysis', {
      params: { start_date: startDate, end_date: endDate, type }
    });
    return response.data;
  }
};

## 5. 详细逻辑设计

### 5.1 报表生成流程

#### 5.1.1 每日报表生成流程

1. 前端进入报表页面，选择"今日"标签
2. 前端发送 API 请求获取今日报表
3. 后端接收请求，解析日期参数
4. 后端查询当日的收支记录数据
5. 按类型（收入/支出）统计总金额
6. 计算净盈亏
7. 按分类统计收入和支出金额
8. 构建报表数据结构
9. 返回报表数据给前端
10. 前端显示报表，包括总览和图表

#### 5.1.2 每周报表生成流程

1. 前端进入报表页面，选择"本周"标签
2. 前端发送 API 请求获取本周报表
3. 后端接收请求，解析起止日期参数
4. 后端查询本周的收支记录数据
5. 按类型（收入/支出）统计总金额
6. 计算净盈亏
7. 按日统计收入和支出金额（用于趋势图）
8. 按分类统计收入和支出金额
9. 构建报表数据结构
10. 返回报表数据给前端
11. 前端显示报表，包括总览、趋势图和分类明细

#### 5.1.3 每月报表生成流程

1. 前端进入报表页面，选择"本月"标签
2. 前端发送 API 请求获取本月报表
3. 后端接收请求，解析年月参数
4. 后端查询本月的收支记录数据
5. 按类型（收入/支出）统计总金额
6. 计算净盈亏
7. 按周统计收入和支出金额（用于趋势图）
8. 按分类统计收入和支出金额
9. 构建报表数据结构
10. 返回报表数据给前端
11. 前端显示报表，包括总览、趋势图和分类明细

### 5.2 报表导出流程

#### 5.2.1 Excel 导出流程

1. 前端在报表页面点击"导出 Excel"按钮
2. 前端发送 API 请求，包含报表数据
3. 后端接收请求，解析报表数据
4. 使用 pandas 和 OpenPyXL 创建 Excel 文件
5. 填充报表数据到 Excel 工作表
6. 格式化 Excel 文件（添加标题、样式等）
7. 将 Excel 文件转换为二进制数据
8. 设置响应头，返回二进制数据给前端
9. 前端接收二进制数据，触发文件下载

#### 5.2.2 PDF 导出流程

1. 前端在报表页面点击"导出 PDF"按钮
2. 前端发送 API 请求，包含报表数据
3. 后端接收请求，解析报表数据
4. 生成 HTML 格式的报表
5. 使用 WeasyPrint 将 HTML 转换为 PDF
6. 将 PDF 文件转换为二进制数据
7. 设置响应头，返回二进制数据给前端
8. 前端接收二进制数据，触发文件下载

### 5.3 报表筛选流程

1. 前端在报表页面设置筛选条件（日期范围、类型、分类等）
2. 前端发送 API 请求，包含筛选条件

  }
  
  if (error) {
    return <div>获取报表失败: {error}</div>;
  }
  
  return (
    <div className="report-page">
      <div className="report-header">
        <h2>经营报表</h2>
        <div className="report-tabs">
          <button 
            className={reportType === 'daily' ? 'active' : ''}
            onClick={() => setReportType('daily')}
          >
            今日
          </button>
          <button 
            className={reportType === 'weekly' ? 'active' : ''}
            onClick={() => setReportType('weekly')}
          >
            本周
          </button>
          <button 
            className={reportType === 'monthly' ? 'active' : ''}
            onClick={() => setReportType('monthly')}
          >
            本月
          </button>
        </div>
        <div className="report-actions">
          <button onClick={() => handleExport('excel')}>导出 Excel</button>
          <button onClick={() => handleExport('pdf')}>导出 PDF</button>
        </div>
      </div>
      
      <div className="report-overview">
        <div className="overview-card">
          <h3>总收入</h3>
          <p className="amount income">¥{reportData?.income || 0}</p>
        </div>
        <div className="overview-card">
          <h3>总支出</h3>
          <p className="amount expense">¥{reportData?.expense || 0}</p>
        </div>
        <div className="overview-card">
          <h3>净盈亏</h3>
          <p className={`amount ${reportData?.profit >= 0 ? 'profit' : 'loss'}`}>
            ¥{reportData?.profit || 0}
          </p>
        </div>
      </div>
      
      <div className="report-charts">
        <div className="chart-container">
          <h3>收支分类</h3>
          <ResponsiveContainer width="100%" height={300}>
            <PieChart>
              <Pie
                data={renderPieData()}
                cx="50%"
                cy="50%"
                labelLine={false}
                label={({ name, percent }) => `${name} ${(percent * 100).toFixed(0)}%`}
                outerRadius={80}
                fill="#8884d8"
                dataKey="value"
              >
                {renderPieData().map((entry, index) => (
                  <Cell key={`cell-${index}`} fill={index % 2 === 0 ? '#8884d8' : '#82ca9d'} />
                ))}
              </Pie>
              <Tooltip />
              <Legend />
            </PieChart>
          </ResponsiveContainer>
        </div>
        
        {renderTrendData().length > 0 && (
          <div className="chart-container">
            <h3>趋势分析</h3>
            <ResponsiveContainer width="100%" height={300}>
              <BarChart data={renderTrendData()}>
                <CartesianGrid strokeDasharray="3 3" />
                <XAxis dataKey={reportType === 'weekly' ? 'date' : 'week'} />
                <YAxis />
                <Tooltip />
                <Legend />
                <Bar dataKey="income" fill="#82ca9d" name="收入" />
                <Bar dataKey="expense" fill="#ffc658" name="支出" />
                <Bar dataKey="profit" fill="#8884d8" name="盈亏" />
              </BarChart>
            </ResponsiveContainer>
          </div>
        )}
      </div>
      
      <div className="report-details">
        <h3>明细数据</h3>
        <table>
          <thead>
            <tr>
              <th>分类</th>
              <th>金额</th>
              <th>占比</th>
            </tr>
          </thead>
          <tbody>
            {reportData && reportData.categories && Object.entries(reportData.categories).map(([name, value]) => (
              <tr key={name}>
                <td>{name}</td>
                <td>¥{value}</td>
                <td>{((value / reportData.income) * 100).toFixed(2)}%</td>
              </tr>
            ))}
          </tbody>
        </table>
      </div>
    </div>
  );
};

export default ReportPage;
