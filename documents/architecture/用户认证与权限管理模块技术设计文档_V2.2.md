# 用户认证与权限管理模块技术设计文档

## 1. 模块概述

用户认证与权限管理模块是 Dot-Store V2.2 系统的基础模块，负责用户注册、登录、权限控制和数据隔离等核心功能。该模块确保系统安全性，为其他业务模块提供身份验证和授权支持。

### 1.1 功能范围

- 用户注册（手机号、邮箱）
- 用户登录（手机号/邮箱+密码）
- 权限管理（店主、店员角色，细粒度权限控制）
- 数据隔离
- 安全控制（密码加密、登录限制）
- API密钥管理（用于MCP服务接入）

### 1.2 技术栈

- 后端：FastAPI + PostgreSQL + SQLAlchemy
- 前端：React + TypeScript + Zustand
- 认证方式：JWT Token
- 密码加密：bcrypt
- 缓存：Redis（用于Token管理和速率限制）

### 1.3 V2.2版本变更

| 变更项 | V2.1 | V2.2 | 变更说明 |
|--------|------|------|----------|
| 权限模型 | 角色基础 | 角色+细粒度权限 | 支持更精细的权限控制 |
| API密钥 | 无 | 支持 | 为MCP服务提供API密钥认证 |
| 权限继承 | 无 | 支持 | 店员权限可继承店主部分权限 |

### 3.2 数据关系

- 用户表是独立表，与其他业务表通过外键关联
- 店主可以管理多个店员，店员归属于一个店主
- 店员通过 `owner_id` 关联到店主
- 店员权限可以继承店主的部分权限

### 3.3 存储方案

- 使用 PostgreSQL 数据库存储用户信息
- 密码使用 bcrypt 算法加密存储
- JWT Token 存储在客户端 localStorage
- API密钥使用 SHA-256 哈希存储

### 4.2 前端 API 调用

#### 4.2.1 API 服务封装

```typescript
// src/services/api.ts
import axios from 'axios';

const api = axios.create({
  baseURL: '/api/v2',
  timeout: 10000,
  headers: {
    'Content-Type': 'application/json',
  },
});

// 请求拦截器
api.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('token');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  },
  (error) => {
    return Promise.reject(error);
  }
);

// 响应拦截器
api.interceptors.response.use(
  (response) => {
    return response.data;
  },
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem('token');
      window.location.href = '/login';
    }
    return Promise.reject(error.response?.data || error.message);
  }
);

export default api;
```

## 5. 详细逻辑设计

### 5.1 认证流程

#### 5.1.1 用户注册流程

1. 前端收集用户注册信息（手机号/邮箱、密码、店铺信息）
2. 后端验证注册信息格式
3. 检查手机号/邮箱是否已存在
4. 对密码进行 bcrypt 加密
5. 创建用户记录，默认角色为店主
6. 返回用户信息

#### 5.1.2 用户登录流程

1. 前端收集登录信息（手机号/邮箱、密码）
2. 后端验证用户是否存在
3. 检查账户是否被锁定
4. 验证密码是否正确
5. 生成 JWT Token
6. 获取用户权限列表
7. 更新最后登录时间
8. 重置登录失败次数
9. 返回 Token 和用户信息（含权限）

### 5.2 权限控制流程

#### 5.2.1 权限检查流程

1. 前端发起 API 请求，携带 JWT Token
2. 后端中间件验证 Token 有效性
3. 解析 Token 获取用户信息
4. 获取用户有效权限（直接权限 + 继承权限）
5. 检查用户是否有权限执行操作
6. 允许或拒绝请求

#### 5.2.2 权限继承逻辑

### 5.3 API密钥管理

#### 5.3.1 生成API密钥流程

1. 用户请求生成API密钥
2. 验证用户身份
3. 检查用户是否已有API密钥
4. 生成随机密钥（格式：sk_xxxxxxxxxxxxxxxx）
5. 存储密钥哈希值
6. 返回明文密钥（仅此一次）

#### 5.3.2 API密钥认证流程

1. 客户端请求携带 `X-API-Key` 头
2. 后端验证密钥格式
3. 查询密钥哈希对应的用户
4. 检查密钥是否有效
5. 获取用户权限
6. 执行请求操作

### 5.4 安全控制

#### 5.4.1 密码安全

- 密码长度至少 8 位，包含字母和数字
- 使用 bcrypt 算法加密存储
- 密码永不明文传输或存储

#### 5.4.2 登录限制

- 登录失败 5 次后锁定账户 30 分钟
- 锁定期间不允许登录尝试
- 锁定时间到期后自动解锁

#### 5.4.3 数据隔离

- 店主可以查看所有数据
- 店员只能查看自己创建的数据和店主授权的数据
- 通过数据库查询条件实现数据隔离

### 5.5 边缘场景处理机制

#### 5.5.1 异常处理

- **网络异常**：处理网络连接超时、断网等情况，提供友好的错误提示
- **服务器异常**：处理服务器内部错误、数据库连接失败等情况，返回统一的错误响应
- **参数错误**：处理请求参数格式错误、缺少必填参数等情况，返回详细的错误信息
- **权限错误**：处理用户无权限访问资源的情况，返回 403 状态码和错误信息

#### 6.3.1 Zustand 状态管理

```typescript
// src/store/authStore.ts
import { create } from 'zustand';
import { authService } from '../services/authService';

interface User {
  id: number;
  phone: string;
  email: string;
  shop_name: string;
  role: string;
  permissions: string[];
}

interface AuthState {
  user: User | null;
  token: string | null;
  isLoading: boolean;
  error: string | null;
  permissions: string[];
  login: (phone: string, password: string) => Promise<void>;
  register: (userData: {
    phone: string;
    email: string;
    password: string;
    shop_name: string;
    shop_type: string;
    city: string;
  }) => Promise<void>;
  logout: () => Promise<void>;
  refreshToken: () => Promise<void>;
  checkAuth: () => Promise<void>;
  checkPermission: (permission: string) => boolean;
  generateApiKey: () => Promise<string>;
}

const useAuthStore = create<AuthState>((set, get) => ({
  user: null,
  token: localStorage.getItem('token'),
  isLoading: false,
  error: null,
  permissions: [],
  
  login: async (phone, password) => {
    set({ isLoading: true, error: null });
    try {
      const response = await authService.login(phone, password);
      if (response.code === 200) {
        set({ 
          user: response.data,
          token: response.data.token,
          permissions: response.data.permissions || [],
          isLoading: false 
        });
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  checkPermission: (permission: string) => {
    const { permissions, user } = get();
    if (user?.role === 'owner') return true;
    return permissions.includes(permission);
  },
  
  generateApiKey: async () => {
    const response = await authService.generateApiKey();
    if (response.code === 200) {
      return response.data.api_key;
    }
    throw new Error(response.message);
  },
  
  // ... 其他方法实现
}));

export default useAuthStore;
```

#### 6.3.2 权限检查组件

```typescript
// src/components/PrivateRoute.tsx
import React from 'react';
import { Navigate } from 'react-router-dom';
import useAuthStore from '../store/authStore';

interface PrivateRouteProps {
  children: React.ReactNode;
  requiredPermission?: string;
}

const PrivateRoute: React.FC<PrivateRouteProps> = ({ children, requiredPermission }) => {
  const { user, isLoading, token, checkPermission } = useAuthStore();
  const isAuthenticated = !!token && !!user;

  if (isLoading) {
    return <div>加载中...</div>;
  }

  if (!isAuthenticated) {
    return <Navigate to="/login" />;
  }

  if (requiredPermission && !checkPermission(requiredPermission)) {
    return <Navigate to="/unauthorized" />;
  }

  return <>{children}</>;
};

export default PrivateRoute;
```

  children,
  onClick,
  type = 'default',

};
