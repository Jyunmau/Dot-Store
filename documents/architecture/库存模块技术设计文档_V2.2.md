# 库存模块技术设计文档

## 1. 模块概述

库存模块是 Dot-Store V2.2 系统的核心业务模块，负责管理店铺的食材库存。该模块基于三层数据模型架构设计，支持食材管理、库存变动追踪、库存预警等功能，并与财务模块集成实现库存价值计算。

### 1.1 功能范围

- 食材管理（创建、查询、更新、删除）
- 库存变动（入库、出库、调整）
- 库存预警（低库存、过期预警）
- 库存盘点
- 库存价值计算
- 库存统计报表

### 1.2 技术栈

- 后端：FastAPI + PostgreSQL + SQLAlchemy
- 前端：React + TypeScript + Zustand
- 数据存储：PostgreSQL（三层数据模型）
- 缓存：Redis

### 1.3 三层数据模型定位

| 层级 | 数据表 | 说明 |
|------|--------|------|
| 交易事实层 | `stock_transactions` | 不可变的库存变动记录 |
| 结构状态层 | `ingredients` | 当前库存状态 |
| 智能分析层 | `stock_value_history` | 库存价值历史趋势 |

### 1.4 V2.2版本变更

| 变更项 | V2.1 | V2.2 | 变更说明 |
|--------|------|------|----------|
| 库存交易 | 无独立表 | `stock_transactions` | 新增交易事实层 |
| 库存价值 | 无 | 支持 | 计算库存总价值 |
| 预警机制 | 简单 | 增强 | 支持多维度预警 |
| 事件日志 | 无 | 支持 | 库存操作记录到事件日志 |

```typescript
// src/store/stockStore.ts
import { create } from 'zustand';
import { Ingredient, StockTransaction, StockWarning, StockSummary } from '../types/stock';
import { stockApi } from '../services/stockService';

interface StockState {
  ingredients: Ingredient[];
  currentIngredient: Ingredient | null;
  transactions: StockTransaction[];
  warnings: StockWarning[];
  summary: StockSummary | null;
  isLoading: boolean;
  error: string | null;
  
  getIngredients: (category?: string) => Promise<void>;
  getIngredient: (id: number) => Promise<void>;
  createIngredient: (data: { name: string; unit: string; min_stock?: number; cost_per_unit?: number }) => Promise<void>;
  updateIngredient: (id: number, data: Partial<Ingredient>) => Promise<void>;
  deleteIngredient: (id: number) => Promise<void>;
  stockIn: (ingredientId: number, quantity: number, cost: number, note?: string) => Promise<void>;
  stockOut: (ingredientId: number, quantity: number, note?: string) => Promise<void>;
  getWarnings: () => Promise<void>;
  getSummary: () => Promise<void>;
  clearError: () => void;
}

const useStockStore = create<StockState>((set, get) => ({
  ingredients: [],
  currentIngredient: null,
  transactions: [],
  warnings: [],
  summary: null,
  isLoading: false,
  error: null,
  
  getIngredients: async (category?: string) => {
    set({ isLoading: true, error: null });
    try {
      const ingredients = await stockApi.getIngredients(category);
      set({ ingredients, isLoading: false });
    } catch (error) {
      set({ error: error instanceof Error ? error.message : '获取食材列表失败', isLoading: false });
    }
  },
  
  stockIn: async (ingredientId, quantity, cost, note) => {
    set({ isLoading: true, error: null });
    try {
      const transaction = await stockApi.stockIn(ingredientId, quantity, cost, note);
      set((state) => ({
        ingredients: state.ingredients.map(i => 
          i.id === ingredientId 
            ? { ...i, current_stock: transaction.stock_after }
            : i
        ),
        isLoading: false
      }));
    } catch (error) {
      set({ error: error instanceof Error ? error.message : '入库失败', isLoading: false });
    }
  },
  
  getWarnings: async () => {
    try {
      const warnings = await stockApi.getWarnings();
      set({ warnings });
    } catch (error) {
      console.error('获取库存预警失败:', error);
    }
  },
  
  clearError: () => set({ error: null }),
}));

export default useStockStore;
```

## 5. 详细逻辑设计

### 5.1 入库流程

```python
async def stock_in(
    user_id: int, 
    ingredient_id: int, 
    quantity: Decimal, 
    cost: Decimal,
    note: str = None
) -> StockTransaction:
    """
    入库操作 - 支持成本计算
    """
    async with db.transaction():
        # 1. 获取食材并加锁
        ingredient = await db.get_ingredient_for_update(user_id, ingredient_id)
        if not ingredient:
            raise IngredientNotFoundError('食材不存在')
        
        # 2. 记录变动前库存
        stock_before = ingredient.current_stock
        
        # 3. 更新库存
        ingredient.current_stock += quantity
        
        # 4. 更新成本单价（加权平均）
        if cost > 0:
            old_total = ingredient.current_stock * ingredient.cost_per_unit
            new_total = quantity * cost
            total_quantity = ingredient.current_stock + quantity
            ingredient.cost_per_unit = (old_total + new_total) / total_quantity
        
        # 5. 创建交易记录
        transaction = StockTransaction(
            user_id=user_id,
            ingredient_id=ingredient_id,
            transaction_no=generate_transaction_no('I'),
            transaction_type=StockTransactionType.PURCHASE,
            quantity=quantity,
            stock_before=stock_before,
            stock_after=ingredient.current_stock,
            unit_cost=cost,
            total_cost=quantity * cost,
            note=note,
            operator_id=get_current_user_id()
        )
        
        # 6. 保存
        await db.save(ingredient)
        await db.save(transaction)
        
        # 7. 记录事件日志
        await event_log_service.log(
            event_type='stock_in',
            entity_type='ingredient',
            entity_id=ingredient_id,
            data={'quantity': str(quantity), 'cost': str(cost)}
        )
        
        return transaction
```

### 5.2 出库流程

```python
async def stock_out(
    user_id: int, 
    ingredient_id: int, 
    quantity: Decimal,
    note: str = None
) -> StockTransaction:
    """
    出库操作 - 检查库存充足
    """
    async with db.transaction():
        # 1. 获取食材并加锁
        ingredient = await db.get_ingredient_for_update(user_id, ingredient_id)
        if not ingredient:
            raise IngredientNotFoundError('食材不存在')
        
        # 2. 检查库存充足
        if ingredient.current_stock < quantity:
            raise InsufficientStockError(f'库存不足: 当前{ingredient.current_stock}, 需要{quantity}')
        
        # 3. 记录变动前库存
        stock_before = ingredient.current_stock
        
        # 4. 更新库存
        ingredient.current_stock -= quantity
        
        # 5. 创建交易记录
        transaction = StockTransaction(
            user_id=user_id,
            ingredient_id=ingredient_id,
            transaction_no=generate_transaction_no('O'),
            transaction_type=StockTransactionType.CONSUME,
            quantity=quantity,
            stock_before=stock_before,
            stock_after=ingredient.current_stock,
            unit_cost=ingredient.cost_per_unit,
            total_cost=quantity * ingredient.cost_per_unit,
            note=note,
            operator_id=get_current_user_id()
        )
        
        # 6. 保存
        await db.save(ingredient)
        await db.save(transaction)
        
        # 7. 记录事件日志
        await event_log_service.log(
            event_type='stock_out',
            entity_type='ingredient',
            entity_id=ingredient_id,
            data={'quantity': str(quantity)}
        )
        
        return transaction
```

```python
async def get_stock_warnings(user_id: int) -> List[dict]:
    """
    获取库存预警列表
    """
    warnings = []
    
    # 1. 低库存预警
    low_stock = await db.query("""
        SELECT id, name, current_stock, min_stock, unit
        FROM ingredients
        WHERE user_id = $1 
          AND status = 'active'
          AND current_stock <= min_stock
          AND min_stock > 0
    """, user_id)
    
    for item in low_stock:
        warnings.append({
            'ingredient_id': item['id'],
            'ingredient_name': item['name'],
            'current_stock': item['current_stock'],
            'min_stock': item['min_stock'],
            'unit': item['unit'],
            'warning_type': 'low_stock',
            'message': f"{item['name']}库存不足，当前{item['current_stock']}{item['unit']}，最低{item['min_stock']}{item['unit']}"
        })
    
    # 2. 过期预警（7天内）
    expiring = await db.query("""
        SELECT id, name, current_stock, expiry_date, unit
        FROM ingredients
        WHERE user_id = $1 
          AND status = 'active'
          AND expiry_date IS NOT NULL
          AND expiry_date <= CURRENT_DATE + INTERVAL '7 days'
          AND expiry_date >= CURRENT_DATE
    """, user_id)
    
    for item in expiring:
        warnings.append({
            'ingredient_id': item['id'],
            'ingredient_name': item['name'],
            'current_stock': item['current_stock'],
            'expiry_date': item['expiry_date'],
            'unit': item['unit'],
            'warning_type': 'expiry',
            'message': f"{item['name']}即将过期，过期日期{item['expiry_date']}"
        })
    
    return warnings
```

```python
async def get_total_stock_value(user_id: int) -> Decimal:
    """
    计算库存总价值
    """
    result = await db.query("""
        SELECT SUM(current_stock * cost_per_unit) as total_value
```

- 库存操作必须在数据库事务中执行
- 使用行锁防止并发问题
- 交易记录不可修改、不可删除
- 金额使用 Decimal 类型
- 记录所有关键操作到事件日志

### 6.2 前端实现注意事项

- 库存数量使用 InputNumber 组件
- 显示库存预警状态
- 支持批量入库操作
- 库存变动实时更新

### 6.3 安全注意事项

- 库存操作需要相应权限
- 出库需要检查库存充足
- 敏感操作记录到事件日志
- 数据隔离按用户ID
