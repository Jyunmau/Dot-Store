# 现金流分析模块技术设计文档

## 1. 模块概述

现金流分析模块是 Dot-Store V2.2 系统新增的智能分析模块，负责分析店铺现金流状况、预测未来现金流、识别财务风险。该模块基于三层数据模型架构设计，为店主提供数据驱动的经营决策支持。

**文档版本**：v2.2.1
**最后更新**：2026年2月22日
**修改说明**：本次更新采纳技术方案评估与优化报告建议，整合设计文档要求（用户语言导航、三色安全指数、风险预警等级）

### 1.1 功能范围

- 现金流趋势分析
- 现金流预测（7天/30天）
- 风险预警（资金不足预警）
- 收支结构分析
- 经营健康度评估
- 分析报告生成
- **三色安全指数展示（V2.2新增）**
- **用户语言导航标签（V2.2新增）**

### 1.2 技术栈

- 后端：FastAPI + PostgreSQL + SQLAlchemy
- 数据分析：NumPy, Pandas
- 数据存储：PostgreSQL
- 缓存：Redis

### 1.3 三层数据模型定位

#### 2.1.4 三色安全指数枚举（V2.2新增）

根据设计文档要求，实现三色安全指数系统：

```python
class SafetyLevel(str, Enum):
    """三色安全等级"""
    SAFE = 'safe'         # 绿色 - 安全区 (80-100分)
    WARNING = 'warning'   # 黄色 - 注意区 (50-79分)
    DANGER = 'danger'     # 红色 - 危险区 (0-49分)

class SafetyIndexCalculator:
    """三色安全指数计算器"""
    
    # 颜色代码
    COLORS = {
        SafetyLevel.SAFE: '#52C41A',     # 绿色
        SafetyLevel.WARNING: '#FAAD14',  # 黄色
        SafetyLevel.DANGER: '#FF4D4F',   # 红色
    }
    
    # 用户友好提示语
    MESSAGES = {
        SafetyLevel.SAFE: '现金流充裕，经营状态良好',
        SafetyLevel.WARNING: '现金流偏紧，建议关注收支情况',
        SafetyLevel.DANGER: '现金流紧张，需要立即采取措施',
    }
    
    @staticmethod
    def calculate(
        cash_balance: Decimal,
        liability: Decimal,
        daily_expense: Decimal
    ) -> dict:
        """
        计算三色安全指数
        
        计算规则：
        - 可用净现金 = 现金余额 - 预收款负债
        - 可运营天数 = 可用净现金 / 日均支出
        - 安全指数 = min(100, 可运营天数 * 2.5)
        
        分级标准：
        - 80-100分（绿色）：可运营天数 > 30天
        - 50-79分（黄色）：可运营天数 7-30天
        - 0-49分（红色）：可运营天数 < 7天
        """
        # 计算可用净现金
        net_available = cash_balance - liability
        
        # 计算可运营天数
        if daily_expense > 0:
            days_of_operation = net_available / daily_expense
        else:
            days_of_operation = 999  # 无支出时视为无限
        
        # 计算安全指数（0-100）
        safety_score = min(100, float(days_of_operation * 2.5))
        safety_score = max(0, safety_score)
        
        # 确定安全等级
        if safety_score >= 80:
            level = SafetyLevel.SAFE
        elif safety_score >= 50:
            level = SafetyLevel.WARNING
        else:
            level = SafetyLevel.DANGER
        
        return {
            'safety_score': round(safety_score, 1),
            'safety_level': level.value,
            'color_code': SafetyIndexCalculator.COLORS[level],
            'message': SafetyIndexCalculator.MESSAGES[level],
            'factors': {
                'cash_balance': float(cash_balance),
                'liability': float(liability),
                'net_available': float(net_available),
                'days_of_operation': round(float(days_of_operation), 1),
            }
        }
```

#### 2.1.5 风险预警等级定义（V2.2新增）

根据设计文档要求，风险预警分为三个等级：

| 预警等级 | 颜色 | 触发条件 | 用户提示语 |
|---------|------|----------|-----------|
| 高风险 | 红色 | 可运营天数 < 7天 | 现金即将耗尽，请立即补充资金 |
| 中风险 | 黄色 | 可运营天数 7-30天 | 现金流偏紧，建议关注收支情况 |
| 低风险 | 绿色 | 可运营天数 > 30天 | 现金流充裕，经营状态良好 |

```python
class RiskAlertLevel(str, Enum):
    """风险预警等级"""
    HIGH = 'high'     # 高风险 - 红色
    MEDIUM = 'medium' # 中风险 - 黄色
    LOW = 'low'       # 低风险 - 绿色

class RiskAlertGenerator:
    """风险预警生成器"""
    
    ALERT_CONFIG = {
        RiskAlertLevel.HIGH: {
            'color': '#FF4D4F',
            'icon': 'exclamation-circle',
            'action_required': True,
            'message': '现金即将耗尽，请立即补充资金',
        },
        RiskAlertLevel.MEDIUM: {
            'color': '#FAAD14',
            'icon': 'warning',
            'action_required': False,
            'message': '现金流偏紧，建议关注收支情况',
        },
        RiskAlertLevel.LOW: {
            'color': '#52C41A',
            'icon': 'check-circle',
            'action_required': False,
            'message': '现金流充裕，经营状态良好',
        },
    }
    
    @staticmethod
    def generate_alert(
        user_id: int,
        safety_index: dict,
        forecast_data: List[dict]
    ) -> Optional[dict]:
        """生成风险预警"""
        level = RiskAlertLevel.LOW
        
        # 根据安全指数和预测数据确定预警等级
        if safety_index['safety_level'] == SafetyLevel.DANGER.value:
            level = RiskAlertLevel.HIGH
        elif safety_index['safety_level'] == SafetyLevel.WARNING.value:
            level = RiskAlertLevel.MEDIUM
        
        # 检查预测数据中是否有负余额
        for forecast in forecast_data:
            if forecast['predicted_balance'] < 0:
                level = RiskAlertLevel.HIGH
                break
        
        config = RiskAlertGenerator.ALERT_CONFIG[level]
        
        return {
            'user_id': user_id,
            'alert_level': level.value,
            'color': config['color'],
            'icon': config['icon'],
            'message': config['message'],
            'action_required': config['action_required'],
            'safety_index': safety_index,
            'created_at': datetime.utcnow().isoformat(),
        }
```

## 5. 详细逻辑设计

### 5.1 现金流分析流程

```python
async def analyze_cash_flow(
    user_id: int, 
    period_start: date, 
    period_end: date
) -> CashFlowAnalysis:
    """
    分析指定周期的现金流
    """
    # 1. 获取收入数据
    income_data = await db.query("""
        SELECT category, SUM(amount) as total
        FROM cash_transactions
        WHERE user_id = $1 
          AND transaction_type = 'income'
          AND DATE(created_at) BETWEEN $2 AND $3
        GROUP BY category
    """, user_id, period_start, period_end)
    
    # 2. 获取支出数据
    expense_data = await db.query("""
        SELECT category, SUM(amount) as total
        FROM cash_transactions
        WHERE user_id = $1 
          AND transaction_type = 'expense'
          AND DATE(created_at) BETWEEN $2 AND $3
        GROUP BY category
    """, user_id, period_start, period_end)
    
    # 3. 计算汇总数据
    total_income = sum(item['total'] for item in income_data)
    total_expense = sum(item['total'] for item in expense_data)
    net_cash_flow = total_income - total_expense
    
    days = (period_end - period_start).days + 1
    avg_daily_income = total_income / days
    avg_daily_expense = total_expense / days
    
    # 4. 构建结构数据
    income_structure = {item['category']: item['total'] for item in income_data}
    expense_structure = {item['category']: item['total'] for item in expense_data}
    
    # 5. 计算健康度评分
    health_score = calculate_health_score(
        total_income, total_expense, net_cash_flow, avg_daily_income
    )
    
    # 6. 评估风险等级
    risk_level = assess_risk_level(net_cash_flow, health_score)
    
    # 7. 生成优化建议
    recommendations = generate_recommendations(
        income_structure, expense_structure, health_score, risk_level
    )
    
    # 8. 创建分析记录
    analysis = CashFlowAnalysis(
        user_id=user_id,
        analysis_date=date.today(),
        analysis_type='period',
        period_start=period_start,
        period_end=period_end,
        total_income=total_income,
        total_expense=total_expense,
        net_cash_flow=net_cash_flow,
        avg_daily_income=avg_daily_income,
        avg_daily_expense=avg_daily_expense,
        income_structure=income_structure,
        expense_structure=expense_structure,
        health_score=health_score,
        risk_level=risk_level,
        recommendations=recommendations
    )
    
    await db.save(analysis)
    
    return analysis
```

```python
import numpy as np
from datetime import timedelta

async def forecast_cash_flow(user_id: int, days: int = 7) -> List[CashFlowForecast]:
    """
    预测未来现金流 - 使用移动平均法
    """
    # 1. 获取历史数据（最近30天）
    history = await db.query("""
        SELECT 
            DATE(created_at) as date,
            SUM(CASE WHEN transaction_type = 'income' THEN amount ELSE 0 END) as income,
            SUM(CASE WHEN transaction_type = 'expense' THEN amount ELSE 0 END) as expense
        FROM cash_transactions
        WHERE user_id = $1 
          AND DATE(created_at) >= CURRENT_DATE - INTERVAL '30 days'
        GROUP BY DATE(created_at)
        ORDER BY date
    """, user_id)
    
    if len(history) < 7:
        # 数据不足，使用简单预测
        return simple_forecast(user_id, days)
    
    # 2. 计算移动平均
    income_values = [h['income'] for h in history]
    expense_values = [h['expense'] for h in history]
    
    # 使用7天移动平均
    window = 7
    avg_income = np.mean(income_values[-window:])
    avg_expense = np.mean(expense_values[-window:])
    
    # 计算标准差用于置信度
    income_std = np.std(income_values[-window:])
    expense_std = np.std(expense_values[-window:])
    
    # 3. 获取当前余额
    current_balance = await cash_service.get_balance(user_id)
    
    # 4. 生成预测
    forecasts = []
    predicted_balance = current_balance
    
    for i in range(1, days + 1):
        target_date = date.today() + timedelta(days=i)
        
        # 预测收入和支出
        predicted_income = Decimal(str(avg_income))
        predicted_expense = Decimal(str(avg_expense))
        predicted_balance = predicted_balance + predicted_income - predicted_expense
        
        # 计算置信度
        confidence = calculate_confidence(income_std, expense_std, i)
        
        # 风险预警
        risk_alert = predicted_balance < 0
        alert_message = None
        if risk_alert:
            alert_message = f"预计{target_date}现金余额不足，请及时补充资金"
        
        forecast = CashFlowForecast(
            user_id=user_id,
            forecast_date=date.today(),
            target_date=target_date,
            predicted_income=predicted_income,
            predicted_expense=predicted_expense,
            predicted_balance=predicted_balance,
            confidence_level=confidence,
            risk_alert=risk_alert,
            alert_message=alert_message
        )
        
        forecasts.append(forecast)
    
    # 5. 保存预测结果
    await db.save_all(forecasts)
    
    return forecasts
```

### 5.3 健康度评分算法

```python
def calculate_health_score(
    total_income: Decimal, 
    total_expense: Decimal, 
    net_cash_flow: Decimal,
    avg_daily_income: Decimal
) -> Decimal:
    """
    计算经营健康度评分 (0-100)
    """
    score = Decimal(0)
    
    # 1. 盈利能力 (30分)
    if total_income > 0:
        profit_margin = net_cash_flow / total_income
        score += min(30, profit_margin * 100)
    
    # 2. 现金流稳定性 (25分)
    if net_cash_flow > 0:
        score += 25
    elif net_cash_flow > -avg_daily_income:
        score += 15
    else:
        score += 5
    
    # 3. 收入规模 (25分)
    if avg_daily_income >= 1000:
        score += 25
    elif avg_daily_income >= 500:
        score += 20
    elif avg_daily_income >= 200:
        score += 15
    else:
        score += 10
    
    # 4. 支出控制 (20分)
    if total_income > 0:
        expense_ratio = total_expense / total_income
        if expense_ratio <= 0.5:
            score += 20
        elif expense_ratio <= 0.7:
            score += 15
        elif expense_ratio <= 0.9:
            score += 10
        else:
            score += 5
    
    return min(100, score)
```

```python
def assess_risk_level(net_cash_flow: Decimal, health_score: Decimal) -> RiskLevel:

    """
    if health_score >= 80 and net_cash_flow > 0:
```
