# 事件日志模块技术设计文档

## 1. 模块概述

事件日志模块是 Dot-Store V2.2 系统的基础支撑模块，负责记录系统中所有关键业务操作。该模块提供完整的操作追溯能力，支持审计、问题排查和数据分析。

### 1.1 功能范围

- 业务事件记录（创建、查询）
- 事件分类管理
- 事件查询和筛选
- 事件统计分析
- 事件导出

### 1.2 技术栈

- 后端：FastAPI + PostgreSQL + SQLAlchemy
- 数据存储：PostgreSQL
- 缓存：Redis

### 1.3 三层数据模型定位

| 层级 | 数据表 | 说明 |
|------|--------|------|
| 交易事实层 | `business_events` | 不可变的事件记录 |
| 结构状态层 | 无 | 事件日志为纯事实记录 |
| 智能分析层 | `event_statistics` | 事件统计分析数据 |

### 1.4 V2.2版本新增功能

| 功能 | 说明 |
|------|------|
| 统一事件日志 | 所有模块关键操作统一记录 |
| 事件分类 | 支持多维度事件分类 |
| 关联追踪 | 支持实体关联和操作链追踪 |
| 异步记录 | 高性能异步事件记录 |

### 3.2 数据关系

- 事件与用户：多对一关系
- 事件与操作人：多对一关系
- 事件与实体：多对一关系（多态）

- 使用 PostgreSQL 数据库存储事件数据
- 事件表按时间分区（按月）
- 历史事件定期归档
- 使用 Redis 缓存近期事件统计

## 5. 详细逻辑设计

### 5.1 事件记录流程

```python
async def log(
    event_type: str,
    entity_type: str = None,
    entity_id: int = None,
    data: dict = None,
    operator_id: int = None,
    operator_type: str = 'user'
) -> BusinessEvent:
    """
    记录业务事件
    """
    # 获取当前用户和请求信息
    current_user = get_current_user()
    request_info = get_request_info()
    
    # 确定事件分类
    event_category = get_event_category(event_type)
    
    # 创建事件记录
    event = BusinessEvent(
        user_id=current_user.id,
        event_type=event_type,
        event_category=event_category,
        entity_type=entity_type,
        entity_id=entity_id,
        operator_id=operator_id or current_user.id,
        operator_type=operator_type,
        data=data,
        ip_address=request_info.get('ip_address'),
        user_agent=request_info.get('user_agent')
    )
    
    # 保存事件
    await db.save(event)
    
    return event
```

### 5.2 异步事件记录

```python
import asyncio
from queue import Queue

# 事件队列
event_queue = Queue()

async def log_async(
    event_type: str,
    entity_type: str = None,
    entity_id: int = None,
    data: dict = None
):
    """
    异步记录事件 - 放入队列由后台任务处理
    """
    event_queue.put({
        'event_type': event_type,
        'entity_type': entity_type,
        'entity_id': entity_id,
        'data': data,
        'user_id': get_current_user_id(),
        'operator_id': get_current_user_id(),
        'operator_type': 'user',
        'ip_address': get_request_ip(),
        'user_agent': get_request_user_agent()
    })

async def event_processor():
    """
    后台事件处理器
    """
    while True:
        try:
            if not event_queue.empty():
                event_data = event_queue.get()
                await save_event(event_data)
            await asyncio.sleep(0.1)
        except Exception as e:
            logger.error(f'Event processor error: {e}')
```

### 5.3 事件查询优化

```python
async def get_events(
    user_id: int,
    filters: dict = None,
    page: int = 1,
    page_size: int = 20
) -> Tuple[List[BusinessEvent], int]:
    """
    获取事件列表 - 支持多条件筛选
    """
    query = db.query(BusinessEvent).filter(BusinessEvent.user_id == user_id)
    
    if filters:
        if filters.get('start_date'):
            query = query.filter(BusinessEvent.created_at >= filters['start_date'])
        if filters.get('end_date'):
            query = query.filter(BusinessEvent.created_at <= filters['end_date'])
        if filters.get('event_type'):
            query = query.filter(BusinessEvent.event_type == filters['event_type'])
        if filters.get('event_category'):
            query = query.filter(BusinessEvent.event_category == filters['event_category'])
        if filters.get('entity_type'):
            query = query.filter(BusinessEvent.entity_type == filters['entity_type'])
        if filters.get('entity_id'):
            query = query.filter(BusinessEvent.entity_id == filters['entity_id'])
    
    total = await query.count()
    events = await query.order_by(BusinessEvent.created_at.desc()) \
        .offset((page - 1) * page_size) \
        .limit(page_size) \
        .all()
    
    return events, total
```

## 6. 实现注意事项

### 6.1 后端实现注意事项

- 事件记录使用异步方式，避免影响主业务性能
- 事件数据不可修改、不可删除
- 敏感数据需要脱敏处理
- 大量事件时使用分页查询

### 6.2 性能注意事项

- 使用事件队列异步处理
- 事件表按时间分区
- 历史事件定期归档
- 查询使用合适的索引

### 6.3 安全注意事项

- 事件日志只读，不可修改
- 敏感数据脱敏存储
- 数据隔离按用户ID
- 导出功能需要权限控制
