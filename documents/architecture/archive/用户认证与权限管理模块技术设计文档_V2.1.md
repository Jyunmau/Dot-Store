# 用户认证与权限管理模块技术设计文档

## 1. 模块概述

用户认证与权限管理模块是 Dot-Store V2.1 系统的基础模块，负责用户注册、登录、权限控制和数据隔离等核心功能。该模块确保系统安全性，为其他业务模块提供身份验证和授权支持。

### 1.1 功能范围

- 用户注册（手机号、邮箱）
- 用户登录（手机号/邮箱+密码）
- 权限管理（店主、店员角色）
- 数据隔离
- 安全控制（密码加密、登录限制）

### 1.2 技术栈

- 后端：FastAPI + PostgreSQL + SQLAlchemy
- 前端：React + TypeScript + Zustand
- 认证方式：JWT Token
- 密码加密：bcrypt
- 缓存：Redis（用于Token管理和速率限制）

### 4.2 前端 API 调用

#### 4.2.1 API 服务封装

```typescript
// src/services/api.ts
import axios from 'axios';

const api = axios.create({
  baseURL: '/api/v1',
  timeout: 10000,
  headers: {
    'Content-Type': 'application/json',
  },
});

// 请求拦截器
api.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('token');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  },
  (error) => {
    return Promise.reject(error);
  }
);

// 响应拦截器
api.interceptors.response.use(
  (response) => {
    return response.data;
  },
  (error) => {
    if (error.response?.status === 401) {
      // 处理未授权
      localStorage.removeItem('token');
      window.location.href = '/login';
    }
    return Promise.reject(error.response?.data || error.message);
  }
);

export default api;
```

import api from './api';

export const authService = {

  login: async (phone: string, password: string) => {
    const response = await api.post('/auth/login', { phone, password });

    }
    return response;
  },

    email: string;
    password: string;

  },

  },

  },
};

## 5. 详细逻辑设计

### 5.1 认证流程

#### 5.1.1 用户注册流程

1. 前端收集用户注册信息（手机号/邮箱、密码、店铺信息）
2. 后端验证注册信息格式
3. 检查手机号/邮箱是否已存在
4. 对密码进行 bcrypt 加密
5. 创建用户记录，默认角色为店主
6. 返回用户信息

#### 5.1.2 用户登录流程

1. 前端收集登录信息（手机号/邮箱、密码）
2. 后端验证用户是否存在
3. 检查账户是否被锁定
4. 验证密码是否正确
5. 生成 JWT Token
6. 更新最后登录时间
7. 重置登录失败次数
8. 返回 Token 和用户信息

### 5.2 权限控制流程

#### 5.2.1 权限检查流程

1. 前端发起 API 请求，携带 JWT Token
2. 后端中间件验证 Token 有效性
3. 解析 Token 获取用户信息
4. 检查用户是否有权限执行操作
5. 允许或拒绝请求

#### 5.2.2 店主管理店员流程

1. 店主登录系统
2. 进入店员管理页面
3. 添加店员：填写店员信息，设置初始密码
4. 移除店员：选择店员，确认移除
5. 更新店员权限：选择权限项，保存设置

### 5.3 安全控制

#### 5.3.1 密码安全

- 密码长度至少 8 位，包含字母和数字
- 使用 bcrypt 算法加密存储
- 密码永不明文传输或存储

#### 5.3.2 登录限制

- 登录失败 5 次后锁定账户 30 分钟
- 锁定期间不允许登录尝试
- 锁定时间到期后自动解锁

#### 5.3.3 数据隔离

- 店主可以查看所有数据
- 店员只能查看自己创建的数据
- 通过数据库查询条件实现数据隔离

### 5.4 边缘场景处理机制

#### 5.4.1 异常处理

- **网络异常**：处理网络连接超时、断网等情况，提供友好的错误提示
- **服务器异常**：处理服务器内部错误、数据库连接失败等情况，返回统一的错误响应
- **参数错误**：处理请求参数格式错误、缺少必填参数等情况，返回详细的错误信息
- **权限错误**：处理用户无权限访问资源的情况，返回 403 状态码和错误信息

#### 5.4.2 错误重试

- **网络错误重试**：对网络错误进行自动重试，最多重试 3 次，每次间隔 1 秒
- **服务器错误重试**：对服务器临时错误（如 503）进行自动重试，最多重试 2 次，每次间隔 2 秒
- **幂等性保证**：确保重试操作不会导致重复数据，使用幂等性设计

#### 5.4.3 降级策略

- **服务降级**：当核心服务不可用时，提供降级服务，确保基本功能可用
- **缓存降级**：当数据库不可用时，使用缓存数据，确保系统能够正常运行
- **功能降级**：当系统负载过高时，暂时关闭非核心功能，确保核心功能可用

### 5.4.5 边缘场景监控和告警机制

- **监控指标**：
  - 登录失败次数和频率
  - 账户锁定次数
  - 权限错误次数
  - API 错误率
  - 响应时间异常

- **告警机制**：
  - **登录失败告警**：当短时间内登录失败次数超过阈值时，发送告警
  - **账户锁定告警**：当账户被锁定时，发送告警通知店主
  - **权限错误告警**：当权限错误次数超过阈值时，发送告警
  - **API 错误告警**：当 API 错误率超过阈值时，发送告警
  - **响应时间告警**：当响应时间超过阈值时，发送告警

- **告警渠道**：
  - 邮件
  - 微信
  - 短信（紧急情况）

- **告警级别**：
  - **警告**：需要关注但不紧急的情况
  - **错误**：需要及时处理的情况
  - **严重**：需要立即处理的紧急情况

### 5.5 数据库性能优化

#### 5.5.1 查询语句优化

- **避免使用 SELECT ***：只选择需要的字段，减少数据传输量
- **合理使用索引**：为常用查询字段创建索引，如手机号、邮箱等
- **避免在 WHERE 子句中使用函数**：会导致索引失效
- **使用参数化查询**：防止 SQL 注入，提高查询性能
- **批量操作**：对批量数据操作使用批量插入、更新，减少数据库交互次数

#### 5.5.2 索引设计

| 表名 | 索引名称 | 索引字段 | 索引类型 | 用途 |
|------|----------|----------|----------|------|
| `users` | `idx_users_phone` | `phone` | `UNIQUE` | 加速手机号查询 |
| `users` | `idx_users_email` | `email` | `UNIQUE` | 加速邮箱查询 |
| `users` | `idx_users_status` | `status` | `BTREE` | 加速状态查询 |
| `users` | `idx_users_role` | `role` | `BTREE` | 加速角色查询 |
| `users` | `idx_users_last_login_at` | `last_login_at` | `BTREE` | 加速登录时间查询 |

#### 5.5.3 数据库性能监控

- **监控指标**：
  - 查询响应时间
  - 连接数使用情况
  - 锁等待时间
  - 索引使用率
  - 表大小和增长趋势

- **监控工具**：
  - PostgreSQL 内置的 `pg_stat_statements` 扩展
  - Prometheus + Grafana
  - pgAdmin

- **优化策略**：
  - 定期分析慢查询日志，优化查询语句
  - 定期重建索引，提高索引效率
  - 根据监控数据调整数据库配置参数
  - 对大表进行分区，提高查询性能

#### 6.3.1 Zustand 状态管理

```typescript
// src/store/authStore.ts
import { create } from 'zustand';
import { authService } from '../services/authService';

interface User {
  id: number;
  phone: string;
  email: string;
  shop_name: string;
  role: string;
}

interface AuthState {
  user: User | null;
  token: string | null;
  isLoading: boolean;
  error: string | null;
  login: (phone: string, password: string) => Promise<void>;
  register: (userData: {
    phone: string;
    email: string;
    password: string;
    shop_name: string;
    shop_type: string;
    city: string;
  }) => Promise<void>;
  logout: () => Promise<void>;
  refreshToken: () => Promise<void>;
  checkAuth: () => Promise<void>;
}

const useAuthStore = create<AuthState>((set, get) => ({
  user: null,
  token: localStorage.getItem('token'),
  isLoading: false,
  error: null,
  
  login: async (phone, password) => {
    set({ isLoading: true, error: null });
    try {
      const response = await authService.login(phone, password);
      if (response.code === 200) {
        set({ 
          user: response.data,
          token: response.data.token,
          isLoading: false 
        });
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  register: async (userData) => {
    set({ isLoading: true, error: null });
    try {
      const response = await authService.register(userData);
      if (response.code !== 200) {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
      set({ isLoading: false });
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  logout: async () => {
    set({ isLoading: true });
    try {
      await authService.logout();
    } catch (error) {
      console.error('Logout error:', error);
    } finally {
      localStorage.removeItem('token');
      set({ user: null, token: null, isLoading: false });
    }
  },
  
  refreshToken: async () => {
    const { token } = get();
    if (!token) return;
    
    set({ isLoading: true });
    try {
      const response = await authService.refreshToken(token);
      if (response.code === 200 && response.data.token) {
        localStorage.setItem('token', response.data.token);
        set({ token: response.data.token, isLoading: false });
      } else {
        set({ isLoading: false });
      }
    } catch (error) {
      set({ isLoading: false });
      // Token刷新失败，清除本地存储并跳转到登录页
      localStorage.removeItem('token');
      set({ user: null, token: null });
      window.location.href = '/login';
    }
  },
  
  checkAuth: async () => {
    const { token } = get();
    if (!token) return;
    
    set({ isLoading: true });
    try {
      const response = await authService.getCurrentUser();
      if (response.code === 200) {
        set({ user: response.data, isLoading: false });
      } else {
        set({ isLoading: false });
        localStorage.removeItem('token');
        set({ user: null, token: null });
      }
    } catch (error) {
      set({ isLoading: false });
      localStorage.removeItem('token');
      set({ user: null, token: null });
    }
  },
}));

export default useAuthStore;
```

#### 6.3.2 权限检查组件

```typescript
// src/components/PrivateRoute.tsx
import React from 'react';
import { Navigate } from 'react-router-dom';
import useAuthStore from '../store/authStore';

interface PrivateRouteProps {
  children: React.ReactNode;
  requiredRole?: string;
}

const PrivateRoute: React.FC<PrivateRouteProps> = ({ children, requiredRole = null }) => {
  const { user, isLoading, token } = useAuthStore();
  const isAuthenticated = !!token && !!user;

  if (isLoading) {
    return <div>加载中...</div>;
  }

  if (!isAuthenticated) {
    return <Navigate to="/login" />;
  }

  if (requiredRole && user?.role !== requiredRole) {
    return <Navigate to="/unauthorized" />;
  }

  return children;
};

export default PrivateRoute;
```
