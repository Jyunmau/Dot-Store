# 备份模块技术设计文档

## 1. 模块概述

备份模块是 Dot-Store V2.1 系统的重要支持模块，负责提供数据备份和恢复功能，确保系统数据的安全性和可靠性。该模块为用户提供数据备份、备份管理和数据恢复功能，帮助店主防范数据丢失风险，保障业务连续性。

### 1.1 功能范围

- 数据备份（手动备份、自动备份）
- 备份管理（查看备份列表、删除备份、下载备份）
- 数据恢复（从备份恢复数据）

### 1.2 技术栈

- 后端：FastAPI + PostgreSQL + SQLAlchemy
- 前端：React + TypeScript + Zustand（状态管理） + React Query（数据获取）
- 数据存储：PostgreSQL 数据库 + 文件系统（备份文件）
- 缓存：Redis（备份状态缓存）

#### 2.2.2 Zustand 状态管理

```typescript
// src/store/backup.ts
import { create } from 'zustand';
import { Backup, BackupCreateParams, BackupSettings, BackupSettingsUpdateParams } from '../types/backup';
import { backupApi } from '../services/backupService';

interface BackupState {
  // 备份数据
  backups: Backup[];
  currentBackup: Backup | null;
  backupSettings: BackupSettings | null;
  
  // 状态
  isLoading: boolean;
  error: string | null;
  
  // 操作
  createBackup: (params: BackupCreateParams) => Promise<void>;
  getBackups: () => Promise<void>;
  getBackup: (id: number) => Promise<void>;
  deleteBackup: (id: number) => Promise<void>;
  downloadBackup: (id: number) => Promise<void>;
  restoreBackup: (id: number) => Promise<void>;
  getBackupSettings: () => Promise<void>;
  updateBackupSettings: (params: BackupSettingsUpdateParams) => Promise<void>;
  clearError: () => void;
}

const useBackupStore = create<BackupState>((set, get) => ({
  // 初始状态
  backups: [],
  currentBackup: null,
  backupSettings: null,
  isLoading: false,
  error: null,
  
  // 创建备份
  createBackup: async (params: BackupCreateParams) => {
    set({ isLoading: true, error: null });
    try {
      const backup = await backupApi.createBackup(params);
      set((state) => ({
        backups: [backup, ...state.backups],
        isLoading: false
      }));
    } catch (error) {
      set({ error: error instanceof Error ? error.message : '创建备份失败', isLoading: false });
    }
  },
  
  // 获取备份列表
  getBackups: async () => {
    set({ isLoading: true, error: null });
    try {
      const backups = await backupApi.getBackups();
      set({ backups, isLoading: false });
    } catch (error) {
      set({ error: error instanceof Error ? error.message : '获取备份列表失败', isLoading: false });
    }
  },
  
  // 获取备份详情
  getBackup: async (id: number) => {
    set({ isLoading: true, error: null });
    try {
      const backup = await backupApi.getBackup(id);
      set({ currentBackup: backup, isLoading: false });
    } catch (error) {
      set({ error: error instanceof Error ? error.message : '获取备份详情失败', isLoading: false });
    }
  },
  
  // 删除备份
  deleteBackup: async (id: number) => {
    set({ isLoading: true, error: null });
    try {
      await backupApi.deleteBackup(id);
      set((state) => ({
        backups: state.backups.filter(backup => backup.id !== id),
        isLoading: false
      }));
    } catch (error) {
      set({ error: error instanceof Error ? error.message : '删除备份失败', isLoading: false });
    }
  },
  
  // 下载备份
  downloadBackup: async (id: number) => {
    set({ isLoading: true, error: null });
    try {
      await backupApi.downloadBackup(id);
      set({ isLoading: false });
    } catch (error) {
      set({ error: error instanceof Error ? error.message : '下载备份失败', isLoading: false });
    }
  },
  
  // 恢复备份
  restoreBackup: async (id: number) => {
    set({ isLoading: true, error: null });
    try {
      await backupApi.restoreBackup(id);
      set({ isLoading: false });
    } catch (error) {
      set({ error: error instanceof Error ? error.message : '恢复备份失败', isLoading: false });
    }
  },
  
  // 获取备份设置
  getBackupSettings: async () => {
    set({ isLoading: true, error: null });
    try {
      const settings = await backupApi.getBackupSettings();
      set({ backupSettings: settings, isLoading: false });
    } catch (error) {
      set({ error: error instanceof Error ? error.message : '获取备份设置失败', isLoading: false });
    }
  },
  
  // 更新备份设置
  updateBackupSettings: async (params: BackupSettingsUpdateParams) => {
    set({ isLoading: true, error: null });
    try {
      const settings = await backupApi.updateBackupSettings(params);
      set({ backupSettings: settings, isLoading: false });
    } catch (error) {
      set({ error: error instanceof Error ? error.message : '更新备份设置失败', isLoading: false });
    }
  },
  
  // 清除错误
  clearError: () => set({ error: null }),
}));

export default useBackupStore;
```

## 3. 数据设计

### 3.1 数据模型

#### 3.1.1 备份表（backups）

```sql
CREATE TABLE backups (
  id               SERIAL PRIMARY KEY,
  user_id          INTEGER NOT NULL,
  name             VARCHAR(64) NOT NULL,
  description      TEXT,
  status           VARCHAR(32) NOT NULL DEFAULT 'pending', -- pending, in_progress, completed, failed
  backup_path      VARCHAR(256) NOT NULL,
  backup_size      INTEGER DEFAULT 0,
  backup_type      VARCHAR(32) NOT NULL DEFAULT 'manual', -- manual, auto
  created_at       TIMESTAMP NOT NULL DEFAULT NOW(),
  completed_at     TIMESTAMP NULL,
  FOREIGN KEY (user_id) REFERENCES users(id)
);

CREATE INDEX idx_backups_user_id ON backups(user_id);
CREATE INDEX idx_backups_status ON backups(status);
CREATE INDEX idx_backups_created_at ON backups(created_at);
CREATE INDEX idx_backups_backup_type ON backups(backup_type);
```

#### 3.1.2 备份设置表（backup_settings）

```sql
CREATE TABLE backup_settings (
  id                     SERIAL PRIMARY KEY,
  user_id                INTEGER NOT NULL UNIQUE,
  auto_backup_enabled    BOOLEAN DEFAULT FALSE,
  backup_schedule        VARCHAR(128) DEFAULT '0 0 * * *', -- cron 表达式，默认每天凌晨执行
  backup_retention_days  INTEGER DEFAULT 7, -- 默认保留7天
  last_auto_backup_at    TIMESTAMP NULL,
  updated_at             TIMESTAMP NOT NULL DEFAULT NOW(),
  FOREIGN KEY (user_id) REFERENCES users(id)
);

CREATE INDEX idx_backup_settings_user_id ON backup_settings(user_id);
```

### 3.2 数据关系

- 备份与用户的关系：按用户ID筛选数据
- 备份设置与用户的关系：每个用户有且仅有一个备份设置

### 3.3 存储方案

- 备份记录和备份设置存储在 PostgreSQL 数据库
- 备份文件存储在文件系统中，路径格式：`/backups/{user_id}/{backup_id}/`
- 备份文件包含数据库转储和必要的配置文件
- 备份文件使用压缩格式存储，减少存储空间

#### 4.2.2 备份服务封装

```typescript
// src/services/backupService.ts
import api from './api';
import { Backup, BackupCreateParams, BackupSettings, BackupSettingsUpdateParams } from '../types/backup';

export const backupApi = {
  // 备份相关
  createBackup: async (params: BackupCreateParams): Promise<Backup> => {
    const response = await api.post('/backups', params);
    return response.data;
  },
  
  getBackups: async (skip: number = 0, limit: number = 100): Promise<Backup[]> => {
    const response = await api.get('/backups', {
      params: { skip, limit }
    });
    return response.data;
  },
  
  getBackup: async (id: number): Promise<Backup> => {
    const response = await api.get(`/backups/${id}`);
    return response.data;
  },
  
  deleteBackup: async (id: number): Promise<void> => {
    await api.delete(`/backups/${id}`);
  },
  
  downloadBackup: async (id: number): Promise<void> => {
    const response = await api.get(`/backups/${id}/download`, {
      responseType: 'blob'
    });
    
    // 创建下载链接
    const url = window.URL.createObjectURL(new Blob([response]));
    const link = document.createElement('a');
    link.href = url;
    link.setAttribute('download', `backup_${id}_${new Date().toISOString().split('T')[0]}.zip`);
    document.body.appendChild(link);
    link.click();
    document.body.removeChild(link);
  },
  
  restoreBackup: async (id: number): Promise<void> => {
    const response = await api.post(`/backups/${id}/restore`);
    return response.data;
  },
  
  // 备份设置相关
  getBackupSettings: async (): Promise<BackupSettings> => {
    const response = await api.get('/backup-settings');
    return response.data;
  },
  
  updateBackupSettings: async (params: BackupSettingsUpdateParams): Promise<BackupSettings> => {
    const response = await api.put('/backup-settings', params);
    return response.data;
  }
};
```

## 5. 详细逻辑设计

### 5.1 备份管理流程

#### 5.1.1 创建手动备份流程

1. 前端进入备份管理页面，点击"创建备份"按钮
2. 前端填写备份名称和描述
3. 前端调用创建备份API
4. 后端接收请求，验证用户权限
5. 后端创建备份记录，状态设置为"pending"
6. 后端异步执行备份操作：
   - 创建备份目录
   - 执行数据库转储
   - 压缩备份文件
   - 更新备份记录状态和大小
7. 后端返回创建成功响应
8. 前端更新备份列表，显示创建成功提示

#### 5.1.2 自动备份流程

1. 后端定时任务检查备份设置
2. 对于启用了自动备份的用户，检查是否到达备份时间
3. 后端创建自动备份记录，状态设置为"pending"
4. 后端执行备份操作：
   - 创建备份目录
   - 执行数据库转储
   - 压缩备份文件
   - 更新备份记录状态和大小
5. 后端更新备份设置中的最后自动备份时间
6. 后端清理过期备份（根据保留天数）

#### 5.1.3 删除备份流程

1. 前端进入备份管理页面，点击备份列表中的"删除"按钮
2. 前端显示删除确认对话框
3. 用户确认删除
4. 前端调用删除备份API
5. 后端接收请求，验证用户权限
6. 后端检查备份是否存在
7. 后端删除备份文件
8. 后端删除备份记录
9. 后端返回删除成功响应
10. 前端更新备份列表，显示删除成功提示

### 5.2 数据恢复流程

#### 5.2.1 从备份恢复数据流程

1. 前端进入备份管理页面，点击备份列表中的"恢复"按钮
2. 前端显示恢复确认对话框，提示恢复操作的风险
3. 用户确认恢复
4. 前端调用恢复备份API
5. 后端接收请求，验证用户权限
6. 后端检查备份是否存在且状态为"completed"
7. 后端执行数据恢复操作：
   - 解压备份文件
   - 验证备份文件完整性
   - 执行数据库恢复
8. 后端返回恢复成功响应
9. 前端显示恢复成功提示，建议用户刷新页面

### 5.3 备份设置流程

#### 5.3.1 更新备份设置流程

1. 前端进入备份设置页面，修改备份设置
2. 前端点击"保存"按钮
3. 前端调用更新备份设置API
4. 后端接收请求，验证用户权限
5. 后端验证备份设置的合法性
6. 后端更新备份设置
7. 如果启用了自动备份，后端重新调度定时任务
8. 后端返回更新成功响应
9. 前端显示更新成功提示

        setIsRestoreModalVisible(false);
      } catch (err) {
        console.error('Failed:', err);
      }
    }
  };
  
  const columns = [
    {
      title: '备份名称',
      dataIndex: 'name',
      key: 'name',
    },
    {
      title: '描述',
      dataIndex: 'description',
      key: 'description',
    },
    {
      title: '类型',
      dataIndex: 'backup_type',
      key: 'backup_type',
      render: (type: string) => type === 'auto' ? '自动' : '手动',
    },
    {
      title: '状态',
      dataIndex: 'status',
      key: 'status',
      render: (status: string) => {
        switch (status) {
          case 'pending':
            return '等待中';
          case 'in_progress':
            return '进行中';
          case 'completed':
            return '已完成';
          case 'failed':
            return '失败';
          default:
            return status;
        }
      },
    },
    {
      title: '大小',
      dataIndex: 'backup_size',
      key: 'backup_size',
      render: (size: number) => `${(size / 1024).toFixed(2)} KB`,
    },
    {
      title: '创建时间',
      dataIndex: 'created_at',
      key: 'created_at',
    },
    {
      title: '完成时间',
      dataIndex: 'completed_at',
      key: 'completed_at',
    },
    {
      title: '操作',
      key: 'action',
      render: (_: any, record: any) => (
        <>
          <Button type="link" onClick={() => handleDownload(record.id)}>下载</Button>
          {record.status === 'completed' && (
            <Button type="link" onClick={() => showRestoreModal(record.id)}>恢复</Button>
          )}
          <Popconfirm
            title="确定要删除这个备份吗？"

            okText="确定"

            <Button type="link" danger>删除</Button>

        </>
      ),
    },
  ];

    <div className="backup-management">
      <div className="header">
        <h2>备份管理</h2>
        <Button type="primary" onClick={showAddModal}>创建备份</Button>
      </div>
      
      <Table 
        columns={columns} 
        dataSource={backups.map(backup => ({ ...backup, key: backup.id }))} 
        loading={isLoading}
        pagination={{ pageSize: 20 }}
      />
      
      <Modal
        title="创建备份"
        open={isModalVisible}
        onOk={handleOk}
        onCancel={() => setIsModalVisible(false)}
      >

          <Form.Item
            name="name"
            label="备份名称"
            rules={[{ required: true, message: '请输入备份名称' }]}
          >
            <Input placeholder="请输入备份名称" />

          <Form.Item
            name="description"
            label="描述"

      </Modal>
