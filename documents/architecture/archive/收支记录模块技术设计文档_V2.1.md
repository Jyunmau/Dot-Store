# 收支记录模块技术设计文档

## 1. 模块概述

收支记录模块是 Dot-Store V2.1 系统的核心业务模块之一，负责收入和支出的记录、管理和分类功能。该模块支持收支分类管理，为用户提供清晰的财务记录工具。

### 1.1 功能范围

- 记录收入（金额、分类、备注等）
- 记录支出（金额、分类、备注、凭证图片等）
- 查看收支列表（按日期、类型、分类筛选）
- 收支分类管理（自定义收入分类、支出分类）
- 关联订单（收入可关联订单）
- 收支数据统计（用于报表生成）

### 1.2 技术栈

- 后端：FastAPI + PostgreSQL + SQLAlchemy
- 前端：React + Zustand（状态管理）+ React Query（数据获取）
- 数据存储：PostgreSQL 数据库
- 文件存储：对象存储（如阿里云 OSS，用于凭证图片）

## 3. 数据设计

### 3.1 数据模型

| 字段名 | 数据类型 | 约束 | 描述 |

| `amount` | `DECIMAL(12,2)` | `NOT NULL` | 金额 |
| `order_id` | `INTEGER` | `REFERENCES orders(id)` | 关联订单ID |
| `note` | `TEXT` | | 备注 |
| `attachment_url` | `VARCHAR(256)` | | 凭证图片URL |
| `created_at` | `TIMESTAMP` | `NOT NULL DEFAULT NOW()` | 创建时间 |
| `updated_at` | `TIMESTAMP` | `NOT NULL DEFAULT NOW()` | 更新时间 |
| `created_by` | `INTEGER` | `REFERENCES users(id)` | 创建人ID |

#### 3.1.2 收支分类表 (`transaction_categories`)

| 字段名 | 数据类型 | 约束 | 描述 |
|--------|----------|------|------|
| `id` | `SERIAL` | `PRIMARY KEY` | 分类ID |
| `user_id` | `INTEGER` | `REFERENCES users(id)` | 用户ID |
| `name` | `VARCHAR(64)` | `NOT NULL` | 分类名称 |
| `type` | `VARCHAR(32)` | `NOT NULL` | 分类类型（income/expense） |
| `description` | `TEXT` | | 分类描述 |
| `created_at` | `TIMESTAMP` | `NOT NULL DEFAULT NOW()` | 创建时间 |
| `updated_at` | `TIMESTAMP` | `NOT NULL DEFAULT NOW()` | 更新时间 |

### 3.2 数据关系

- 收支记录表与用户表：多对一关系（一个用户可以有多个收支记录）
- 收支记录表与订单表：多对一关系（多个收支记录可以关联同一个订单）
- 收支记录表与收支分类表：多对一关系（多个收支记录可以属于同一个分类）

### 3.3 存储方案

- 使用 PostgreSQL 数据库存储收支记录和分类数据
- 凭证图片使用对象存储（如阿里云 OSS）存储
- 图片上传后返回 URL 存储在收支记录的 `attachment_url` 字段
- 考虑使用 Redis 缓存热点数据，如当日收支统计

// src/services/api.ts
import axios from 'axios';

const api = axios.create({
  baseURL: '/api/v1',
  timeout: 10000,
  headers: {
    'Content-Type': 'application/json',
  },
});

// 请求拦截器
api.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('token');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  },
  (error) => {
    return Promise.reject(error);
  }
);

// 响应拦截器
api.interceptors.response.use(
  (response) => {
    return response.data;
  },
  (error) => {
    if (error.response?.status === 401) {
      // 处理未授权
      localStorage.removeItem('token');
      window.location.href = '/login';
    }
    return Promise.reject(error.response?.data || error.message);
  }
);

export default api;

import api from './api';

export const transactionService = {
  // 创建收支记录
  createTransaction: async (transactionData: {
    type: 'income' | 'expense';
    category: string;
    amount: number;

## 5. 详细逻辑设计

### 5.1 收支记录流程

#### 5.1.1 记录收入流程

1. 前端进入收入记录页面
2. 用户填写收入信息（金额、分类、备注等）
3. 可选：关联订单（选择已有的订单）
4. 前端验证收入信息格式
5. 发送 API 请求创建收入记录
6. 后端验证请求参数
7. 创建收入记录，设置类型为 "income"
8. 关联订单（如果有）
9. 返回收入记录信息给前端
10. 前端显示创建成功提示，更新收支列表

#### 5.1.2 记录支出流程

1. 前端进入支出记录页面
2. 用户填写支出信息（金额、分类、备注等）
3. 可选：上传凭证图片
4. 前端验证支出信息格式
5. 如果有凭证图片，先上传图片获取 URL
6. 发送 API 请求创建支出记录，包含图片 URL
7. 后端验证请求参数
8. 创建支出记录，设置类型为 "expense"
9. 保存凭证图片 URL（如果有）
10. 返回支出记录信息给前端
11. 前端显示创建成功提示，更新收支列表

#### 5.1.3 查看收支列表流程

1. 前端进入收支列表页面
2. 用户选择筛选条件（日期范围、类型、分类）
3. 前端发送 API 请求获取收支列表
4. 后端根据筛选条件查询数据库
5. 对查询结果进行分页处理
6. 返回收支列表数据给前端
7. 前端显示收支列表，支持排序和进一步筛选

### 5.2 收支分类管理流程

#### 5.2.1 创建收支分类流程

1. 前端进入收支分类管理页面
2. 用户填写分类信息（名称、类型、描述）
3. 前端验证分类信息格式
4. 发送 API 请求创建分类
5. 后端验证请求参数
6. 创建分类记录
7. 返回分类信息给前端
8. 前端显示创建成功提示，更新分类列表

#### 5.2.2 更新收支分类流程

1. 前端进入收支分类管理页面
2. 用户修改分类信息
3. 前端验证修改后的信息格式
4. 发送 API 请求更新分类
5. 后端验证请求参数
6. 更新分类信息，记录修改时间
7. 返回更新后的分类信息给前端
8. 前端显示更新成功提示，更新分类列表

### 5.3 收支汇总统计流程

1. 前端进入报表页面
2. 用户选择日期范围
3. 前端发送 API 请求获取收支汇总统计
4. 后端根据日期范围查询数据库
5. 按类型和分类统计收支金额
6. 计算净盈亏
7. 返回汇总统计数据给前端
8. 前端显示收支汇总报表

// src/store/transactionStore.ts
import { create } from 'zustand';
import { transactionService } from '../services/transactionService';

interface Transaction {
  transaction_id: number;
  user_id: number;
  type: 'income' | 'expense';
  category: string;
  amount: number;
  order_id?: number;
  note?: string;
  attachment_url?: string;
  created_at: string;
  updated_at: string;
  created_by: number;

interface TransactionCategory {
  category_id: number;
  user_id: number;
  name: string;
  type: 'income' | 'expense';
  description?: string;
  created_at: string;
  updated_at: string;
}

interface TransactionSummary {
  income: number;
  expense: number;
  net_profit: number;
  categories: Record<string, number>;
}

interface TransactionState {
  transactions: Transaction[];
  currentTransaction: Transaction | null;
  categories: TransactionCategory[];
  summary: TransactionSummary | null;
  isLoading: boolean;
  error: string | null;
  createTransaction: (transactionData: {
    type: 'income' | 'expense';
    category: string;
    amount: number;
    order_id?: number;
    note?: string;
    attachment_url?: string;
  }) => Promise<void>;
  listTransactions: (filters?: {
    start_date?: string;
    end_date?: string;
    type?: 'income' | 'expense';
    category?: string;
  }) => Promise<void>;
  getTransaction: (transactionId: number) => Promise<void>;
  updateTransaction: (transactionId: number, transactionData: {
    category?: string;
    amount?: number;
    order_id?: number;
    note?: string;
    attachment_url?: string;
  }) => Promise<void>;
  deleteTransaction: (transactionId: number) => Promise<void>;
  getTransactionSummary: (startDate?: string, endDate?: string) => Promise<void>;
  listCategories: (type?: 'income' | 'expense') => Promise<void>;
  createCategory: (categoryData: {
    name: string;
    type: 'income' | 'expense';
    description?: string;
  }) => Promise<void>;
}

const useTransactionStore = create<TransactionState>((set, get) => ({
  transactions: [],
  currentTransaction: null,
  categories: [],
  summary: null,
  isLoading: false,
  error: null,
  
  createTransaction: async (transactionData) => {
    set({ isLoading: true, error: null });
    try {
      const response = await transactionService.createTransaction(transactionData);
      if (response.code === 200 && response.data) {
        set((state) => ({
          transactions: [response.data, ...state.transactions],
          isLoading: false,
        }));
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  listTransactions: async (filters) => {
    set({ isLoading: true, error: null });
    try {
      const response = await transactionService.listTransactions(filters);
      if (response.code === 200) {
        set({ transactions: response.data || [], isLoading: false });
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  getTransaction: async (transactionId) => {
    set({ isLoading: true, error: null });
    try {
      const response = await transactionService.getTransaction(transactionId);
      if (response.code === 200 && response.data) {
        set({ currentTransaction: response.data, isLoading: false });
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  updateTransaction: async (transactionId, transactionData) => {
    set({ isLoading: true, error: null });
    try {
      const response = await transactionService.updateTransaction(transactionId, transactionData);
      if (response.code === 200 && response.data) {
        set((state) => ({
          transactions: state.transactions.map(transaction => 
            transaction.transaction_id === transactionId ? response.data! : transaction
          ),
          currentTransaction: response.data,
          isLoading: false,
        }));
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  deleteTransaction: async (transactionId) => {
    set({ isLoading: true, error: null });
    try {
      const response = await transactionService.deleteTransaction(transactionId);
      if (response.code === 200) {
        set((state) => ({
          transactions: state.transactions.filter(transaction => transaction.transaction_id !== transactionId),
          isLoading: false,
        }));
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  getTransactionSummary: async (startDate, endDate) => {
    set({ isLoading: true, error: null });
    try {
      const response = await transactionService.getTransactionSummary(startDate, endDate);
      if (response.code === 200 && response.data) {
        set({ summary: response.data, isLoading: false });
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  listCategories: async (type) => {
    set({ isLoading: true, error: null });
    try {
      const response = await transactionService.listCategories(type);
      if (response.code === 200) {
        set({ categories: response.data || [], isLoading: false });
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  createCategory: async (categoryData) => {
    set({ isLoading: true, error: null });
    try {
      const response = await transactionService.createCategory(categoryData);
      if (response.code === 200 && response.data) {
        set((state) => ({
          categories: [response.data, ...state.categories],
          isLoading: false,
        }));
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
}));

export default useTransactionStore;

import React, { useState } from 'react';

### 7.4 数据库性能优化

#### 7.4.1 查询语句优化

- **避免使用 SELECT ***：只选择需要的字段，减少数据传输量
- **合理使用索引**：为常用查询字段创建索引，如用户ID、类型、分类、创建时间等
- **避免在 WHERE 子句中使用函数**：会导致索引失效
- **使用参数化查询**：防止 SQL 注入，提高查询性能
- **批量操作**：对批量数据操作使用批量插入、更新，减少数据库交互次数
- **分页查询**：使用 LIMIT 和 OFFSET 进行分页，避免一次性查询大量数据
- **使用连接池**：配置合理的数据库连接池大小，避免连接泄露

#### 7.4.2 索引设计

### 7.5 边缘场景处理机制

#### 7.5.1 异常处理

- **网络异常**：处理网络连接超时、断网等情况，提供友好的错误提示
- **服务器异常**：处理服务器内部错误、数据库连接失败等情况，返回统一的错误响应
- **参数错误**：处理请求参数格式错误、缺少必填参数等情况，返回详细的错误信息
- **权限错误**：处理用户无权限访问资源的情况，返回 403 状态码和错误信息
- **文件上传异常**：处理文件上传失败、文件过大、文件类型错误等情况，返回详细的错误信息

#### 7.5.2 错误重试

- **网络错误重试**：对网络错误进行自动重试，最多重试 3 次，每次间隔 1 秒
- **服务器错误重试**：对服务器临时错误（如 503）进行自动重试，最多重试 2 次，每次间隔 2 秒
- **幂等性保证**：确保重试操作不会导致重复数据，使用幂等性设计

#### 7.5.3 降级策略

- **服务降级**：当核心服务不可用时，提供降级服务，确保基本功能可用
- **缓存降级**：当数据库不可用时，使用缓存数据，确保系统能够正常运行
- **功能降级**：当系统负载过高时，暂时关闭非核心功能，确保核心功能可用
- **文件上传降级**：当对象存储服务不可用时，暂时存储文件到本地，待服务恢复后再上传
