# 订单管理模块技术设计文档

## 1. 模块概述

订单管理模块是 Dot-Store V2.1 系统的核心业务模块之一，负责订单的快速记录、查看、编辑和管理功能。该模块支持订单分类和标签管理，为用户提供便捷的订单操作体验。

### 1.1 功能范围

- 快速记录订单（金额、订单类型、标签等）
- 查看订单列表（按日期、类型、标签筛选）
- 编辑订单（修改订单信息、删除订单）
- 订单分类管理（自定义订单分类）
- 订单标签管理（自定义订单标签）
- 订单回收站（删除的订单进入回收站，支持恢复）

### 1.2 技术栈

- 后端：FastAPI + PostgreSQL + SQLAlchemy
- 前端：React + Zustand（状态管理）+ React Query（数据获取）
- 数据存储：PostgreSQL 数据库
- 缓存：Redis（可选，用于热点数据缓存）

### 3.2 数据关系

- 订单表与用户表：多对一关系（一个用户可以有多个订单）
- 订单表与订单分类表：多对一关系（一个订单属于一个分类）

### 3.3 存储方案

- 使用 PostgreSQL 数据库存储订单数据
- 订单元数据使用 JSONB 类型存储，支持灵活的扩展字段
- 订单标签使用数组类型存储，便于查询和筛选
- 考虑使用 Redis 缓存热点数据，如当日订单统计

#### 4.2.1 API 服务封装

```typescript
// src/services/api.ts
import axios from 'axios';

const api = axios.create({
  baseURL: '/api/v1',
  timeout: 10000,
  headers: {
    'Content-Type': 'application/json',
  },
});

// 请求拦截器
api.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('token');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  },
  (error) => {
    return Promise.reject(error);
  }
);

// 响应拦截器
api.interceptors.response.use(
  (response) => {
    return response.data;
  },
  (error) => {
    if (error.response?.status === 401) {
      // 处理未授权
      localStorage.removeItem('token');
      window.location.href = '/login';
    }
    return Promise.reject(error.response?.data || error.message);
  }
);

export default api;
```

```typescript
import api from './api';

export const orderService = {

  createOrder: async (orderData: {

    tags?: string[];
    metadata?: Record<string, any>;

    }
    return await api.get(`/orders?${params.toString()}`);
  },
```

## 5. 详细逻辑设计

### 5.1 订单管理流程

#### 5.1.1 快速记录订单流程

1. 前端进入订单记录页面
2. 用户填写订单信息（金额、订单类型、标签等）
3. 前端验证订单信息格式
4. 发送 API 请求创建订单
5. 后端验证请求参数
6. 创建订单记录，设置默认状态为 "created"
7. 保存订单元数据（如客户信息、备注等）
8. 返回订单信息给前端
9. 前端显示创建成功提示，更新订单列表

#### 5.1.2 查看订单列表流程

1. 前端进入订单列表页面
2. 用户选择筛选条件（日期范围、订单类型、标签）
3. 前端发送 API 请求获取订单列表
4. 后端根据筛选条件查询数据库
5. 对查询结果进行分页处理
6. 返回订单列表数据给前端
7. 前端显示订单列表，支持排序和进一步筛选

#### 5.1.3 编辑订单流程

1. 前端进入订单详情页面
2. 用户修改订单信息
3. 前端验证修改后的信息格式
4. 发送 API 请求更新订单
5. 后端验证请求参数
6. 更新订单信息，记录修改时间
7. 返回更新后的订单信息给前端
8. 前端显示更新成功提示，更新订单列表

#### 5.1.4 删除订单流程

1. 前端选择要删除的订单
2. 显示删除确认对话框
3. 用户确认删除操作
4. 前端发送 API 请求删除订单
5. 后端执行软删除操作（设置 is_deleted 为 true）
6. 记录删除时间
7. 返回删除成功消息给前端
8. 前端从订单列表中移除该订单，更新回收站列表

### 5.2 订单分类管理流程

#### 5.2.1 创建订单分类流程

1. 前端进入订单分类管理页面
2. 用户填写分类信息（名称、描述）
3. 前端验证分类信息格式
4. 发送 API 请求创建分类
5. 后端验证请求参数
6. 创建分类记录
7. 返回分类信息给前端
8. 前端显示创建成功提示，更新分类列表

#### 5.2.2 更新订单分类流程

1. 前端进入订单分类管理页面
2. 用户修改分类信息
3. 前端验证修改后的信息格式
4. 发送 API 请求更新分类
5. 后端验证请求参数
6. 更新分类信息，记录修改时间
7. 返回更新后的分类信息给前端
8. 前端显示更新成功提示，更新分类列表

```typescript
  currentOrder: null,
  recycleOrders: [],
  isLoading: false,
  error: null,
  
  createOrder: async (orderData) => {
    set({ isLoading: true, error: null });
    try {
      const response = await orderService.createOrder(orderData);
      if (response.code === 200 && response.data) {
        set((state) => ({
          orders: [response.data, ...state.orders],
          isLoading: false,
        }));
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  listOrders: async (filters) => {
    set({ isLoading: true, error: null });
    try {
      const response = await orderService.listOrders(filters);
      if (response.code === 200) {
        set({ orders: response.data || [], isLoading: false });
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  getOrder: async (orderId) => {
    set({ isLoading: true, error: null });
    try {
      const response = await orderService.getOrder(orderId);
      if (response.code === 200 && response.data) {
        set({ currentOrder: response.data, isLoading: false });
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  updateOrder: async (orderId, orderData) => {
    set({ isLoading: true, error: null });
    try {
      const response = await orderService.updateOrder(orderId, orderData);
      if (response.code === 200 && response.data) {
        set((state) => ({
          orders: state.orders.map(order => 
            order.order_id === orderId ? response.data! : order
          ),
          currentOrder: response.data,
          isLoading: false,
        }));
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  deleteOrder: async (orderId) => {
    set({ isLoading: true, error: null });
    try {
      const response = await orderService.deleteOrder(orderId);
      if (response.code === 200) {
        set((state) => ({
          orders: state.orders.filter(order => order.order_id !== orderId),
          isLoading: false,
        }));
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  restoreOrder: async (orderId) => {
    set({ isLoading: true, error: null });
    try {
      const response = await orderService.restoreOrder(orderId);
      if (response.code === 200) {
        // 从回收站移除，添加到正常订单列表
        set((state) => ({
          recycleOrders: state.recycleOrders.filter(order => order.order_id !== orderId),
          isLoading: false,
        }));
        // 重新获取订单列表
        get().listOrders();
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
  
  getRecycleOrders: async () => {
    set({ isLoading: true, error: null });
    try {
      const response = await orderService.getRecycleOrders();
      if (response.code === 200) {
        set({ recycleOrders: response.data || [], isLoading: false });
      } else {
        set({ error: response.message, isLoading: false });
        throw new Error(response.message);
      }
    } catch (error) {
      set({ error: error.message, isLoading: false });
      throw error;
    }
  },
}));

export default useOrderStore;
```

### 7.4 数据库性能优化

#### 7.4.1 查询语句优化

- **避免使用 SELECT ***：只选择需要的字段，减少数据传输量
- **合理使用索引**：为常用查询字段创建索引，如用户ID、创建时间、订单类型等
- **避免在 WHERE 子句中使用函数**：会导致索引失效
- **使用参数化查询**：防止 SQL 注入，提高查询性能
- **批量操作**：对批量数据操作使用批量插入、更新，减少数据库交互次数
- **分页查询**：使用 LIMIT 和 OFFSET 进行分页，避免一次性查询大量数据
- **使用连接池**：配置合理的数据库连接池大小，避免连接泄露

#### 7.4.2 索引设计

### 7.5 边缘场景处理机制

#### 7.5.1 异常处理

- **网络异常**：处理网络连接超时、断网等情况，提供友好的错误提示
- **服务器异常**：处理服务器内部错误、数据库连接失败等情况，返回统一的错误响应
- **参数错误**：处理请求参数格式错误、缺少必填参数等情况，返回详细的错误信息
- **权限错误**：处理用户无权限访问资源的情况，返回 403 状态码和错误信息

#### 7.5.2 错误重试

- **网络错误重试**：对网络错误进行自动重试，最多重试 3 次，每次间隔 1 秒
- **服务器错误重试**：对服务器临时错误（如 503）进行自动重试，最多重试 2 次，每次间隔 2 秒
- **幂等性保证**：确保重试操作不会导致重复数据，使用幂等性设计

#### 7.5.3 降级策略

- **服务降级**：当核心服务不可用时，提供降级服务，确保基本功能可用
- **缓存降级**：当数据库不可用时，使用缓存数据，确保系统能够正常运行
- **功能降级**：当系统负载过高时，暂时关闭非核心功能，确保核心功能可用
