# 现金账户模块技术设计文档

## 1. 模块概述

现金账户模块是 Dot-Store V2.2 系统新增的核心财务模块，负责管理店铺现金账户、现金收支记录和账户余额追踪。该模块基于三层数据模型架构设计，确保财务数据的强一致性和可追溯性。

### 1.1 功能范围

- 现金账户管理（查询、状态管理）
- 现金收入记录（订单收入、充值收入、其他收入）
- 现金支出记录（采购支出、费用支出、其他支出）
- 账户余额查询（实时余额、可重建余额）
- 收支记录查询
- 账户间转账

### 1.2 技术栈

- 后端：FastAPI + PostgreSQL + SQLAlchemy
- 前端：React + TypeScript + Zustand
- 数据存储：PostgreSQL（三层数据模型）
- 缓存：Redis（账户余额缓存）

### 1.3 三层数据模型定位

| 层级 | 数据表 | 说明 |
|------|--------|------|
| 交易事实层 | `cash_transactions` | 不可变的交易记录，所有收支记录 |
| 结构状态层 | `cash_accounts` | 可重建的账户状态，当前余额 |
| 智能分析层 | `cash_balance_history` | 余额历史趋势分析数据 |

### 1.4 V2.2版本新增功能

| 功能 | 说明 |
|------|------|
| 现金账户 | 统一管理店铺现金资产 |
| 收支分类 | 支持自定义收支分类 |
| 余额可重建 | 所有余额可从交易记录重建 |
| 交易不可变 | 所有交易记录不可修改、不可删除 |
| 事件溯源 | 关键操作记录到业务事件日志 |

#### 2.2.2 Zustand 状态管理

```typescript
// src/store/cashStore.ts
import { create } from 'zustand';
import { CashAccount, CashTransaction, CashSummary } from '../types/cash';
import { cashApi } from '../services/cashService';

interface CashState {
  account: CashAccount | null;
  transactions: CashTransaction[];
  summary: CashSummary | null;
  isLoading: boolean;
  error: string | null;
  
  getAccount: () => Promise<void>;
  recordIncome: (data: { amount: number; category: string; note?: string; order_id?: number }) => Promise<void>;
  recordExpense: (data: { amount: number; category: string; note?: string }) => Promise<void>;
  getTransactions: (filters?: { start_date?: string; end_date?: string; category?: string }) => Promise<void>;
  getSummary: (startDate: string, endDate: string) => Promise<void>;
  clearError: () => void;
}

const useCashStore = create<CashState>((set) => ({
  account: null,
  transactions: [],
  summary: null,
  isLoading: false,
  error: null,
  
  getAccount: async () => {
    set({ isLoading: true, error: null });
    try {
      const account = await cashApi.getAccount();
      set({ account, isLoading: false });
    } catch (error) {
      set({ error: error instanceof Error ? error.message : '获取账户失败', isLoading: false });
    }
  },
  
  recordIncome: async (data) => {
    set({ isLoading: true, error: null });
    try {
      const transaction = await cashApi.recordIncome(data);
      set((state) => ({
        account: state.account ? {
          ...state.account,
          balance: transaction.balance_after,
          total_income: state.account.total_income + data.amount
        } : null,
        transactions: [transaction, ...state.transactions],
        isLoading: false
      }));
    } catch (error) {
      set({ error: error instanceof Error ? error.message : '记录收入失败', isLoading: false });
    }
  },
  
  recordExpense: async (data) => {
    set({ isLoading: true, error: null });
    try {
      const transaction = await cashApi.recordExpense(data);
      set((state) => ({
        account: state.account ? {
          ...state.account,
          balance: transaction.balance_after,
          total_expense: state.account.total_expense + data.amount
        } : null,
        transactions: [transaction, ...state.transactions],
        isLoading: false
      }));
    } catch (error) {
      set({ error: error instanceof Error ? error.message : '记录支出失败', isLoading: false });
    }
  },
  
  clearError: () => set({ error: null }),
}));

export default useCashStore;
```

### 3.2 数据一致性保证

#### 3.2.1 交易原子性

```python
async def record_income(
    user_id: int, 
    amount: Decimal, 
    category: str, 
    note: str,
    order_id: int = None,
    customer_transaction_id: int = None
) -> CashTransaction:
    """
    记录收入 - 使用数据库事务保证原子性
    """
    async with db.transaction():
        # 1. 获取账户并加锁
        account = await db.get_cash_account_for_update(user_id)
        
        # 2. 记录交易前余额
        balance_before = account.balance
        
        # 3. 更新账户余额
        account.balance += amount
        account.total_income += amount
        account.version += 1
        
        # 4. 创建交易记录
        transaction = CashTransaction(
            user_id=user_id,
            account_id=account.id,
            transaction_no=generate_transaction_no('I'),
            transaction_type=CashTransactionType.INCOME,
            category=category,
            amount=amount,
            balance_before=balance_before,
            balance_after=account.balance,
            order_id=order_id,
            customer_transaction_id=customer_transaction_id,
            note=note,
            operator_id=get_current_user_id()
        )
        
        # 5. 保存
        await db.save(account)
        await db.save(transaction)
        
        # 6. 记录业务事件
        await event_log_service.log(
            event_type='cash_income',
            entity_type='cash_account',
            entity_id=account.id,
            data={'amount': str(amount), 'category': category, 'transaction_no': transaction.transaction_no}
        )
        
        return transaction
```

## 5. 详细逻辑设计

### 5.1 记录收入流程

1. 前端提交收入请求（金额、分类、备注）
2. 后端验证用户权限
3. 验证金额有效性
4. 开启数据库事务
5. 获取账户记录并加锁
6. 记录交易前余额
7. 更新账户余额和累计收入
8. 创建交易记录
9. 记录业务事件日志
10. 提交事务
11. 更新Redis缓存
12. 返回交易结果

### 5.2 记录支出流程

1. 前端提交支出请求（金额、分类、备注）
2. 后端验证用户权限
3. 验证金额有效性和余额充足
4. 开启数据库事务
5. 获取账户记录并加锁
6. 验证余额充足
7. 记录交易前余额
8. 扣减账户余额，增加累计支出
9. 创建交易记录
10. 记录业务事件日志
11. 提交事务
12. 更新Redis缓存
13. 返回交易结果

### 5.3 与其他模块的集成

| 触发场景 | 操作 | 说明 |
|----------|------|------|
| 订单完成 | 记录收入 | 订单金额计入现金账户收入 |
| 客户充值 | 记录收入 | 充值金额计入现金账户收入 |
| 客户消费 | 无需操作 | 消费从预收款扣除，不涉及现金 |
| 采购支出 | 记录支出 | 采购金额计入现金账户支出 |

## 6. 实现注意事项

### 6.1 后端实现注意事项

- 所有交易操作必须在数据库事务中执行
- 使用行锁防止并发问题
- 交易记录不可修改、不可删除
- 金额使用 Decimal 类型
- 记录所有关键操作到业务事件日志

### 6.2 前端实现注意事项

- 金额输入使用 InputNumber 组件
- 显示交易前后余额变化
- 支持交易记录分页加载
- 提供收支分类选择

### 6.3 安全注意事项

- 收支操作需要相应权限
- 大额交易需要二次确认
- 敏感操作记录到事件日志
- 定期执行余额校验
