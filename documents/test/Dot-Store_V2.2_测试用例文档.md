## 1. 测试概述

### 1.1 测试范围

本测试用例集覆盖Dot-Store V2.2版本的所有功能模块，包括：

- 用户认证与权限管理模块（V2.2新增API密钥功能）
- 订单管理模块（V2.2新增订单项、支付记录）
- 客户账户模块（V2.2新增，三层数据模型）
- 现金账户模块（V2.2新增，三层数据模型）
- 库存模块（V2.2新增库存流水）
- 现金流分析模块（V2.2新增）
- 财务快照模块（V2.2新增）
- 事件日志模块（V2.2新增）

### 1.2 测试类型

| 测试类型 | 数量 | 说明 |
|---------|------|------|
| 单元测试 | 120+ | 覆盖后端接口的输入验证、业务逻辑和异常处理 |
| 集成测试 | 50+ | 覆盖前端操作交互流程及前后端数据交互 |
| 总计 | 170+ | - |

### 1.3 测试环境

- 后端：FastAPI + PostgreSQL 15+ + Redis 7.0+
- 前端：React 18+ + TypeScript 5.0+ + Ant Design 5.0+
- 测试框架：pytest（后端）+ Jest + React Testing Library（前端）
- 数据库：PostgreSQL Test Database
- 缓存：Redis Test Instance

### 1.4 三层数据模型测试原则

根据V2.2版本的三层数据模型架构，测试需遵循以下原则：

1. **交易事实层测试**：验证所有交易记录不可篡改
2. **结构状态层测试**：验证余额可由流水重建
3. **智能分析层测试**：验证分析数据的准确性和完整性
