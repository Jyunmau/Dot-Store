## 1. 页面结构总览

### 1.1 信息架构

#### 1.1.1 V2.2信息架构（V2.2优化）

```
仪表盘（首页）
  ├─ 现金流概览
  ├─ 安全指数
  └─ 风险预警

记录
  ├─ 订单
  ├─ 收支
  └─ 库存

洞察（AI分析）
  ├─ 钱从哪里来（收入结构）
  ├─ 钱花哪里了（成本结构）
  ├─ 什么时候赚钱（盈亏平衡）
  └─ 未来剩多少（现金流预测）

报表
  ├─ 日报
  ├─ 周报
  └─ 月报

设置
  ├─ 用户信息
  ├─ 店铺信息
  ├─ 提醒设置
  └─ 系统设置
```

#### 1.1.2 V2.1信息架构对比

```
V2.1信息架构：
首页
  ├─ 今日概览
  ├─ 快速记录
  └─ 最近记录

记录
  ├─ 订单记录
  ├─ 收入记录
  ├─ 成本记录
  └─ 库存记录

报表
  ├─ 日报表
  ├─ 周报表
  └─ 月报表

设置
  ├─ 用户信息
  ├─ 店铺信息
  └─ 系统设置
```

**V2.2主要变化（优化后）：**
1. 首页改为仪表盘，聚焦现金流安全
2. "分析"模块改为"洞察"，使用用户语言命名
3. 简化导航层级，从5层减少到4层
4. 记录模块简化为订单、收支、库存三个子项

### 1.2 页面层级

#### 1.2.1 一级页面（优化后）

**一级页面列表：**
1. 仪表盘（Dashboard）
2. 记录（Records）
3. 洞察（Insights）
4. 报表（Reports）
5. 设置（Settings）

#### 1.2.2 二级页面（优化后）

**二级页面列表：**
1. 记录模块
   - 订单
   - 收支（收入+成本合并）
   - 库存

2. 洞察模块
   - 钱从哪里来（收入结构）
   - 钱花哪里了（成本结构）
   - 什么时候赚钱（盈亏平衡）
   - 未来剩多少（现金流预测）

3. 报表模块
   - 日报
   - 周报
   - 月报

4. 设置模块
   - 用户信息
   - 店铺信息
   - 提醒设置
   - 系统设置

### 9.2 数据状态

#### 9.2.1 数据加载

**数据加载说明：**
- 使用React Query进行数据加载
- 支持数据缓存
- 支持数据刷新

**数据加载示例：**
```jsx
const { data, isLoading, error, refetch } = useQuery('data', fetchData);

if (isLoading) {
  return <Skeleton />;
}

if (error) {
  return <ErrorState onRetry={refetch} />;
}

if (!data || data.length === 0) {
  return <EmptyState />;
}

return <DataList data={data} />;
```

#### 9.2.2 数据更新

**数据更新说明：**
- 使用React Query Mutation进行数据更新
- 支持乐观更新
- 支持错误回滚

**数据更新示例：**
```jsx
const mutation = useMutation(updateData, {
  onMutate: async (newData) => {
    await queryClient.cancelQueries('data');
    const previousData = queryClient.getQueryData('data');
    queryClient.setQueryData('data', (old) => [...old, newData]);
    return { previousData };
  },
  onError: (err, newData, context) => {
    queryClient.setQueryData('data', context.previousData);
  },
  onSettled: () => {
    queryClient.invalidateQueries('data');
  },
});
```

```jsx
const { register, handleSubmit, formState: { errors, isSubmitting } } = useForm();

const onSubmit = async (data) => {

    await mutation.mutateAsync(data);

    console.error(error);
  }
};

return (
  <form onSubmit={handleSubmit(onSubmit)}>
    <Input
      {...register('name', { required: '请输入名称' })}
      error={errors.name}
    />
    <Button type="submit" loading={isSubmitting}>
      提交
    </Button>
  </form>
);
```
