## 1. 页面总体结构

### 1.1 一级导航

**导航结构：**
```
┌─────────────────────────────────┐
│  [Logo]  [搜索]  [用户头像]     │
├─────────────────────────────────┤
│                              │
│         [页面内容]            │
│                              │
├─────────────────────────────────┤
│  🏠  📝  📊  ⚙️       │
│  今日  记录  报表  设置     │
└─────────────────────────────────┘
```

**导航说明：**
- **今日**：首页，显示今日盈亏和记录
- **记录**：订单、收支记录管理
- **报表**：数据报表和统计分析
- **设置**：系统设置和用户管理

### 1.2 核心用户操作路径

```
打开系统
  ↓
查看「今天」（今日页面）
  ↓
新增一条记录（快速记录）
  ↓
晚些时候补充 / 修正（记录页面）
  ↓
查看今天盈亏（今日页面）
  ↓
查看一段时间报表（报表页面）
  ↓
调整设置（设置页面）
```

## 2. 页面级原型设计

### 2.1 今日页面

#### 2.1.1 页面结构

```
┌─────────────────────────────────┐
│  Dot-Store              🔍 👤  │
├─────────────────────────────────┤
│  今日盈亏概览                │
│  ┌───────────────────────────┐ │

│  │  ¥1,258  ¥832  ¥426      │ │
│  │  ↑12%    ↓8%   ↑15%       │ │
│  └───────────────────────────┘ │
├─────────────────────────────────┤
│  快速记录                      │
│  ┌───────────────────────────┐ │
│  │  [+ 记一笔]  [+ 订单]    │ │
│  │  [+ 收入]  [+ 支出]      │ │
│  └───────────────────────────┘ │
├─────────────────────────────────┤
│  今日发生了什么                │
│  ┌───────────────────────────┐ │
│  │  📦 订单 #001  ¥128       │ │
│  │  14:30  外卖  待补        │ │
│  ├───────────────────────────┤ │
│  │  💰 收入  ¥1,000          │ │
│  │  12:00  现金收入          │ │
│  ├───────────────────────────┤ │
│  │  💸 支出  ¥500            │ │
│  │  10:00  购买食材          │ │
│  └───────────────────────────┘ │
├─────────────────────────────────┤

│  今日  记录  报表  设置     │
└─────────────────────────────────┘
```

#### 2.1.2 组件说明

**今日盈亏概览卡片：**
- 显示今日收入、支出、盈亏
- 显示环比变化（与昨日对比）
- 使用颜色区分（收入-绿色，支出-红色，盈亏-蓝色）
- 支持点击查看详情

**快速记录按钮组：**
- 4个快速记录按钮
- 按钮高度：48px
- 按钮间距：8px
- 支持点击展开详细表单

**今日记录列表：**
- 按时间倒序排列
- 显示记录类型、金额、时间、状态
- 支持点击查看详情
- 支持下拉刷新
- 支持上拉加载更多

#### 2.1.3 响应式设计

**移动端（< 640px）：**
- 单列布局
- 卡片全宽
- 底部导航

**平板端（640px - 1023px）：**
- 双列布局
- 左列：盈亏概览 + 快速记录
- 右列：今日记录列表
- 顶部导航

**桌面端（≥ 1024px）：**
- 三列布局
- 左列：盈亏概览
- 中列：快速记录 + 今日记录列表
- 右列：快捷操作
- 侧边导航

## 6. 页面与后台概念映射

### 6.1 映射关系

| 页面概念 | 后台概念 | 说明 |
|---------|---------|------|
| 今日盈亏 | Order + Ledger + Event | 聚合今日订单、账本、事件数据 |
| 订单记录 | Order | 订单表 |
| 收支记录 | Transaction | 交易表 |
| 记录列表 | Order + Transaction | 订单和交易联合查询 |
| 报表数据 | Order + Ledger + Event | 聚合查询结果 |
| 用户信息 | User | 用户表 |
| 店铺信息 | Store | 店铺表 |
| 库存预警 | Inventory | 库存表 |
| 会员积分 | Member | 会员表 |
| 数据备份 | Backup | 备份表 |

### 6.2 数据流说明

#### 6.2.1 今日盈亏数据流

```
前端请求今日盈亏
  ↓
后端查询Order表（今日订单）
  ↓
后端查询Ledger表（今日账本）
  ↓
后端查询Event表（今日事件）
  ↓
后端聚合计算收入、支出、盈亏
  ↓
后端返回今日盈亏数据
  ↓
前端显示今日盈亏概览
```

#### 6.2.2 记录列表数据流

```
前端请求记录列表
  ↓
后端查询Order表（订单记录）
  ↓
后端查询Transaction表（收支记录）
  ↓
后端联合查询并排序
  ↓
后端返回记录列表数据
  ↓
前端显示记录列表
```

#### 6.2.3 报表数据流

```
前端请求报表数据
  ↓
后端查询Order表（订单数据）
  ↓
后端查询Ledger表（账本数据）
  ↓
后端查询Event表（事件数据）
  ↓
后端聚合计算报表数据
  ↓
后端返回报表数据
  ↓
前端显示报表图表和明细
```
