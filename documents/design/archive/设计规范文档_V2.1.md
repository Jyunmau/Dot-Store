## 1. 设计原则

### 1.1 核心设计原则

#### 1.1.1 极简设计原则

**原则说明：**
- 界面简洁，去除冗余元素
- 信息层级清晰，重点突出
- 留白充足，避免拥挤

**设计标准：**
- 页面留白比例 ≥ 30%
- 单屏信息密度 ≤ 60%
- 主要操作按钮 ≤ 3个
- 次要信息可折叠

**应用示例：**
```jsx
// 好的设计：简洁清晰
<Card>
  <CardHeader>今日盈亏</CardHeader>
  <CardContent>
    <Stat label="收入" value="¥1,258" trend="+12%" />
    <Stat label="支出" value="¥832" trend="-8%" />
    <Stat label="盈亏" value="¥426" trend="+15%" />
  </CardContent>
</Card>

// 不好的设计：信息过载
<Card>
  <CardHeader>今日盈亏</CardHeader>
  <CardContent>
    <Stat label="收入" value="¥1,258" trend="+12%" />
    <Stat label="支出" value="¥832" trend="-8%" />
    <Stat label="盈亏" value="¥426" trend="+15%" />
    <Stat label="订单数" value="45" trend="+5%" />
    <Stat label="客单价" value="¥28" trend="-3%" />
    <Stat label="毛利率" value="35%" trend="+2%" />
  </CardContent>
</Card>
```

#### 1.1.2 移动优先原则

**原则说明：**
- 优先考虑移动端体验
- 触摸目标最小44px×44px
- 避免复杂的手势操作
- 优化单手操作

**设计标准：**
- 触摸目标尺寸 ≥ 44px×44px
- 按钮高度 ≥ 48px（移动端）
- 输入框高度 ≥ 48px（移动端）
- 导航高度 ≥ 64px（移动端）

**应用示例：**
```jsx
// 好的设计：触摸目标足够大
<Button height="48px" onClick={handleClick}>
  保存
</Button>

// 不好的设计：触摸目标太小
<Button height="32px" onClick={handleClick}>
  保存
</Button>
```

#### 1.1.3 快速操作原则

**原则说明：**
- 减少操作步骤
- 提供快捷操作入口
- 支持批量操作
- 优化表单填写

**设计标准：**
- 核心操作步骤 ≤ 3步
- 表单必填字段 ≤ 5个
- 支持快捷键操作
- 支持批量操作

**应用示例：**
```jsx
// 好的设计：快速记录
<QuickRecord>
  <RecordTypeSelect />
  <AmountInput />
  <SaveButton />
</QuickRecord>

// 不好的设计：复杂表单
<RecordForm>
  <RecordTypeSelect />
  <AmountInput />
  <CustomerInput />
  <AddressInput />
  <PhoneInput />
  <RemarkInput />
  <TagInput />
  <SaveButton />
</RecordForm>
```

#### 1.1.4 清晰反馈原则

**原则说明：**
- 每个操作都有明确的视觉反馈
- 加载状态清晰可见
- 错误提示友好明确
- 成功提示及时出现

**设计标准：**
- 按钮点击反馈时间 ≤ 100ms
- 加载状态显示延迟 ≤ 200ms
- 错误提示显示时间 ≤ 500ms
- 成功提示显示时间 ≤ 300ms

**应用示例：**
```jsx
// 好的设计：清晰的反馈
<Button onClick={handleClick} loading={isLoading}>
  {isLoading ? '保存中...' : '保存'}
</Button>

// 不好的设计：无反馈
<Button onClick={handleClick}>
  保存
</Button>
```

#### 1.1.5 品牌一致原则

**原则说明：**
- 统一的品牌色彩
- 统一的图标风格
- 统一的字体系统
- 统一的交互模式

**设计标准：**
- 品牌色使用一致
- 图标风格统一（线性/填充）
- 字体系统统一
- 交互模式统一

**应用示例：**
```jsx
// 好的设计：品牌一致
<Button variant="primary" color="primary">
  保存
</Button>
<Icon name="save" variant="outline" />

// 不好的设计：品牌不一致
<Button variant="primary" color="custom">
  保存
</Button>
<Icon name="save" variant="filled" />
```

### 1.2 用户中心原则

#### 1.2.1 用户不是"系统使用者"，而是"生意记录者"

**原则说明：**
- 不要求用户理解ERP/财务/流程
- 不强制完整输入
- 永远允许"先记下来"
- 使用业务语言而非技术语言

**设计标准：**
- 使用业务语言
- 支持不完整输入
- 支持后续补充
- 友好的错误提示

**应用示例：**
```jsx
// 好的设计：业务语言
<RecordForm>
  <Field label="订单金额" required />
  <Field label="订单类型" />
  <Field label="备注" />
</RecordForm>

// 不好的设计：技术语言
<RecordForm>
  <Field label="销售金额" required />
  <Field label="销售渠道" />
  <Field label="备注说明" />
</RecordForm>
```

#### 1.2.2 页面 ≠ 功能模块

**原则说明：**
- 页面按用户认知组织
- 后台模块（Order/Ledger/Event）对用户不可见
- 使用业务语言而非技术语言

**设计标准：**
- 页面按用户认知组织
- 隐藏技术细节
- 使用业务语言

**应用示例：**
```jsx
// 好的设计：用户认知
<Page title="今日">
  <TodaySummary />
  <QuickRecord />
  <TodayRecords />
</Page>

// 不好的设计：技术视角
<Page title="Dashboard">
  <OrderSummary />
  <LedgerSummary />
  <EventSummary />
</Page>
```

#### 1.2.3 一切围绕「今天」

**原则说明：**
- 今天发生了什么
- 今天赚没赚
- 今天哪里不对

**设计标准：**
- 首页默认显示今日数据
- 报表默认显示今日报表
- 预警提示今日异常
- 快速记录默认记录今天

**应用示例：**
```jsx
// 好的设计：围绕今天
<Page title="今日">
  <TodaySummary />
  <QuickRecord />
  <TodayRecords />
</Page>

// 不好的设计：不围绕今天
<Page title="数据概览">
  <DateRangePicker />
  <Summary />
  <Records />
</Page>
```

## 2. 色彩系统

### 2.1 主色调

#### 2.1.1 主色定义

```css
:root {
  --color-primary: #3B82F6;
  --color-primary-light: #DBEAFE;
  --color-primary-dark: #1D4ED8;
  --color-primary-gradient: linear-gradient(135deg, #3B82F6 0%, #2563EB 100%);
}
```

**使用规范：**
- 主色用于主要操作按钮（保存、提交、确认）
- 主色浅用于背景高亮（选中状态、hover状态）
- 主色深用于按钮激活状态（按下状态）
- 主色渐变用于品牌化元素

#### 2.1.2 主色对比度

| 颜色 | 色值 | 对比度（白底） | 是否达标 |
|------|------|--------------|--------|
| 主色 | #3B82F6 | 4.5:1 | ✅ |
| 主色浅 | #DBEAFE | 1.5:1 | ❌ |
| 主色深 | #1D4ED8 | 7.1:1 | ✅ |

**对比度要求：**
- WCAG AA标准：4.5:1
- WCAG AAA标准：7:1
- 主色浅仅用于背景，不用于文字

## 3. 排版系统

### 3.1 字体系统

#### 3.1.1 字体定义

```css
:root {
  /* 字体族 */
  --font-family-base: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif;
  --font-family-display: 'Inter', sans-serif;
  --font-family-mono: 'SF Mono', Monaco, 'Cascadia Code', 'Roboto Mono', Consolas, 'Courier New', monospace;
  
  /* 字号 */
  --font-size-display: 48px;
  --font-size-h1: 36px;
  --font-size-h2: 30px;
  --font-size-h3: 24px;
  --font-size-h4: 20px;
  --font-size-body: 16px;
  --font-size-small: 14px;
  --font-size-tiny: 12px;
  
  /* 行高 */
  --line-height-display: 56px;
  --line-height-h1: 44px;
  --line-height-h2: 38px;
  --line-height-h3: 32px;
  --line-height-h4: 28px;
  --line-height-body: 24px;
  --line-height-small: 21px;
  --line-height-tiny: 18px;
  
  /* 字重 */
  --font-weight-light: 300;
  --font-weight-regular: 400;
  --font-weight-medium: 500;
  --font-weight-semibold: 600;
  --font-weight-bold: 700;
  
  /* 字间距 */
  --letter-spacing-tight: -0.025em;
  --letter-spacing-normal: 0;
  --letter-spacing-wide: 0.025em;
}
```

#### 3.1.2 字号系统

| 类型 | 字号 | 行高 | 字重 | 字间距 | 用途 |
|------|------|------|------|--------|------|
| Display | 48px | 56px | 700 | -0.025em | 展示型大标题 |
| H1 | 36px | 44px | 700 | -0.025em | 页面主标题 |
| H2 | 30px | 38px | 600 | -0.025em | 章节标题 |
| H3 | 24px | 32px | 600 | 0 | 卡片标题 |
| H4 | 20px | 28px | 600 | 0 | 次级标题 |
| Body | 16px | 24px | 400 | 0 | 正文文字 |
| Small | 14px | 21px | 400 | 0 | 辅助文字 |
| Tiny | 12px | 18px | 400 | 0 | 小字说明 |

#### 3.1.3 字重系统

| 字重 | 数值 | 用途 |
|------|------|------|
| Light | 300 | 辅助文字、描述 |
| Regular | 400 | 正文文字 |
| Medium | 500 | 次要标题、标签 |
| Semibold | 600 | 主要标题、按钮 |
| Bold | 700 | 强调文字、品牌元素 |

### 3.2 排版使用规范

#### 3.2.1 排版使用原则

**排版使用原则：**
1. **层级清晰**：使用不同的字号、字重、颜色建立信息层级
2. **一致性**：相同层级的文字使用相同的样式
3. **可读性**：确保文字与背景的对比度符合WCAG标准
4. **响应式**：字号和行高在不同设备上自适应

#### 3.2.2 排版使用示例

```jsx
// 页面标题
<Typography variant="h1">今日盈亏概览</Typography>

// 卡片标题
<Typography variant="h3">核心指标</Typography>

// 正文文字
<Typography variant="body">今日收入¥1,258，支出¥832，盈亏¥426</Typography>

// 辅助文字
<Typography variant="small">较昨日增长12%</Typography>

// 小字说明
<Typography variant="tiny">数据更新时间：2024-02-07 14:30</Typography>
```

## 4. 间距系统

### 4.1 间距定义

```css
:root {
  /* 间距 */
  --spacing-0: 0px;
  --spacing-px: 1px;
  --spacing-0-5: 2px;
  --spacing-1: 4px;
  --spacing-1-5: 6px;
  --spacing-2: 8px;
  --spacing-3: 12px;
  --spacing-4: 16px;
  --spacing-5: 20px;
  --spacing-6: 24px;
  --spacing-8: 32px;
  --spacing-10: 40px;
  --spacing-12: 48px;
  --spacing-16: 64px;
  
  /* 内边距 */
  --padding-xs: 4px 8px;
  --padding-sm: 8px 12px;
  --padding-md: 12px 16px;
  --padding-lg: 16px 24px;
  --padding-xl: 24px 32px;
  
  /* 外边距 */
  --margin-xs: 4px 8px;
  --margin-sm: 8px 12px;
  --margin-md: 12px 16px;
  --margin-lg: 16px 24px;
  --margin-xl: 24px 32px;
}
```

### 4.2 间距使用规范

#### 4.2.1 间距使用原则

**间距使用原则：**
1. **8px网格**：所有间距均为8px的倍数
2. **一致性**：相同类型的元素使用相同的间距
3. **留白充足**：确保页面留白比例 ≥ 30%
4. **视觉平衡**：保持视觉平衡，避免拥挤

#### 4.2.2 间距使用示例

```jsx
// 组件内间距
<Card padding="md">
  <CardContent>
    <Typography variant="h3">标题</Typography>
    <Typography variant="body" marginTop="2">内容</Typography>
  </CardContent>
</Card>

// 组件间距
<Stack spacing="4">
  <Card>卡片1</Card>
  <Card>卡片2</Card>
  <Card>卡片3</Card>
</Stack>

// 页面间距
<Page padding="6">
  <Header />
  <Main marginTop="6">
    <Section marginBottom="8">区块1</Section>
    <Section marginBottom="8">区块2</Section>
  </Main>
</Page>
```
