## 版本对比

### V1.0 → V2.1 主要变化

| 方面 | V1.0 | V2.1 |
|------|--------|--------|
| 实施策略 | 分阶段（阶段一+阶段二） | 一次性实施 |
| 功能范围 | 基础优化+品牌建设 | 完整功能模块（用户认证、订单管理、收支记录、报表、库存、会员、备份、PWA） |
| 设计风格 | 现代简约+品牌强化 | 极简设计+移动优先+品牌化 |
| 图标系统 | Heroicons开源图标 | 自定义品牌图标系统 |
| 成就系统 | 有 | 无（聚焦核心功能） |
| 响应式设计 | 基础响应式 | 移动优先，PWA支持 |
| 无障碍支持 | WCAG AA | WCAG 2.1 AA |
