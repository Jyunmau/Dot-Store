## 设计原则

Dot-Store V2.1的设计遵循以下核心原则：

1. **极简设计原则**
   - 界面简洁，去除冗余元素
   - 信息层级清晰，重点突出
   - 留白充足，避免拥挤

2. **移动优先原则**
   - 优先考虑移动端体验
   - 触摸目标最小44px×44px
   - 避免复杂的手势操作
   - 优化单手操作

3. **快速操作原则**
   - 减少操作步骤
   - 提供快捷操作入口
   - 支持批量操作
   - 优化表单填写

4. **清晰反馈原则**
   - 每个操作都有明确的视觉反馈
   - 加载状态清晰可见
   - 错误提示友好明确
   - 成功提示及时出现

5. **品牌一致原则**
   - 统一的品牌色彩
   - 统一的图标风格
   - 统一的字体系统
   - 统一的交互模式

6. **用户不是"系统使用者"，而是"生意记录者"**
   - 不要求用户理解ERP/财务/流程
   - 不强制完整输入
   - 永远允许"先记下来"
   - 使用业务语言而非技术语言

7. **页面 ≠ 功能模块**
   - 页面按用户认知组织
   - 后台模块（Order/Ledger/Event）对用户不可见
   - 使用业务语言而非技术语言

8. **一切围绕「今天」**
   - 今天发生了什么
   - 今天赚没赚
   - 今天哪里不对
