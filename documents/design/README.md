## 设计原则

Dot-Store V2.2的设计遵循以下核心原则：

### 核心设计原则

1. **确定性优先原则**
   - 让用户看清未来3个月的现金流
   - 提供明确的盈亏平衡点
   - 给出具体的优化建议
   - 建立经营确定性

2. **情绪安全感原则**
   - 通过三色仪表盘提供情绪安全感
   - 提前预警风险，避免恐慌
   - 给出具体行动建议，减少焦虑
   - 建立用户信任

3. **极简设计原则**
   - 界面简洁，去除冗余元素
   - 信息层级清晰，重点突出
   - 留白充足，避免拥挤

4. **移动优先原则**
   - 优先考虑移动端体验
   - 触摸目标最小48px×48px
   - 避免复杂的手势操作
   - 优化单手操作

5. **清晰反馈原则**
   - 每个操作都有明确的视觉反馈
   - 加载状态清晰可见
   - 错误提示友好明确
   - 成功提示及时出现

6. **品牌一致原则**
   - 统一的品牌色彩
   - 统一的图标风格
   - 统一的字体系统
   - 统一的交互模式

### 用户中心原则

1. **用户是"生活方式型主理人"**
   - 不要求用户理解财务术语
   - 使用业务语言而非技术语言
   - 关注用户的情感需求（安全感、确定性）
   - 提供智能洞察，而非原始数据

2. **用户语言原则**
   - 收入结构分析 → 钱从哪里来
   - 成本结构分析 → 钱花哪里了
   - 盈亏平衡分析 → 什么时候赚钱
   - 现金流预测 → 未来剩多少

3. **渐进式披露原则**
   - 核心信息优先展示
   - 次要信息按需获取
   - 减少用户认知负荷

4. **页面按用户认知组织**
   - 页面按用户认知组织
   - 后台模块（Order/Ledger/Event）对用户不可见
   - 使用业务语言而非技术语言

5. **一切围绕"现金流安全"**
   - 首页默认显示现金流概览
   - 洞察页面提供现金流预测
   - 风险预警提示现金流风险
   - 周报月报关注现金流变化

**核心特点：**
- 确定性现金流 + 情绪安全感 + 智能洞察
- 一次性实施，不再分阶段
- 精简的色彩系统（17种基础色）
- 统一组件状态规范
- 完整的响应式设计（6个断点）
