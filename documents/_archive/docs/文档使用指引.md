## 四、快速查找指南

### 按任务类型查找

1. **如果您需要了解系统架构**：
   - 先看根目录 `README.md` 的「技术栈实现」和「三层架构说明」
   - 再根据需要查看 `kernel/`、`platforms/` 或 `script/` 目录下的README.md

2. **如果您需要开发API接口**：
   - 查看 `script/README.md` 了解路由设计
   - 查看对应模块的路由文件（如 `apps/api-server/script/routes/order.py`）

3. **如果您需要开发数据库相关功能**：
   - 查看 `database-design.md` 了解表结构
   - 查看对应模块的模型文件（如 `apps/api-server/kernel/models/order.py`）

4. **如果您需要开发前端组件**：
   - 查看 `设计系统规范.md` 了解UI设计要求
   - 参考现有前端组件实现

5. **如果您需要了解特定功能需求**：
   - 查找对应的PRD文档（如 `天堂股东体验卡PRD功能说明书.md`）
   - 查看特定项目目录下的相关文档

### 按文档类型查找

- **架构设计文档**：位于 `kernel/`、`platforms/`、`script/` 目录下
- **技术实现文档**：`database-design.md`、`设计系统规范.md`、`微服务架构设计.md`
- **业务需求文档**：`天堂股东体验卡PRD功能说明书.md` 和 `天堂电影酒馆需求及分层架构调整/` 目录下的文档
- **文档管理文档**：`README.md`、`文档更新机制.md`、`文档使用指引.md`

## 六、常见问题解答

### Q1：如何确定我需要查看哪个文档？
A1：根据您的任务类型，参考本指引中的「如何根据任务类型查找文档」和「快速查找指南」部分，即可找到所需文档。

### Q2：如果我找不到所需文档怎么办？
A2：首先检查 `README.md` 文档目录索引，确认文档是否存在。如果确实不存在，可能需要创建新文档或更新现有文档。

### Q3：如何更新文档？
A3：参考 `文档更新机制.md` 中的更新流程，包括文档创建、更新、审核和维护规则。

### Q4：特定项目文档如何使用？
A4：特定项目文档（如「天堂电影酒馆需求及分层架构调整」）包含了项目的需求、设计和任务分解，适合在进行该项目开发时参考。
