# Dot-Store 设计系统规范

## 1. 设计理念

Dot-Store 设计系统的核心理念是简洁、高效、易用，旨在为用户提供清晰、直观的界面体验。设计系统遵循以下原则：

- **简洁明了**：界面简洁，信息层级清晰，减少用户认知负担
- **高效实用**：功能优先，操作流程简单，提高用户工作效率
- **一致统一**：组件样式和交互统一，提供连贯的用户体验
- **响应式设计**：适配不同屏幕尺寸，提供良好的跨设备体验

## 3. 排版系统

| H2 | 24px | 32px | 600 | 章节标题 |

## 4. 间距系统

采用 8px 网格系统，所有间距均为 8px 的倍数：

| 间距 | 尺寸 | 用途 |
|------|------|------|
| XS | 4px | 小间距、内边距 |
| S | 8px | 基础间距、组件内间距 |
| M | 16px | 中等间距、组件间距 |
| L | 24px | 大间距、页面区块间距 |
| XL | 32px | 超大间距、页面间距 |
| XXL | 48px | 页面级间距 |

## 8. 交互设计规范

### 8.1  hover 状态

- 按钮：背景色加深，阴影增强
- 卡片：阴影增强，轻微上浮 (2px)
- 链接：文字色加深
- 菜单项：背景色变为浅灰2 (#F5F5F5)

### 8.2 点击状态

- 按钮：背景色进一步加深，阴影减弱
- 文字按钮：背景色变为主色浅 (#E6F7FF)

### 8.3 加载状态

- 加载动画：旋转动画，主色边框
- 按钮加载：显示加载动画，禁用点击

### 8.4 过渡动画

- 过渡时间：0.2s
- 过渡效果：ease
- 适用元素：按钮、卡片、导航项、输入框

## 9. 响应式设计规范

### 9.1 断点

| 设备类型 | 断点 | 布局调整 |
|----------|------|----------|
| 移动端 | < 768px | 隐藏侧边导航，显示顶部和底部导航，单列布局 |
| 平板端 | 768px - 1199px | 隐藏侧边导航，显示顶部导航，双列布局 |
| 桌面端 | ≥ 1200px | 显示侧边导航，隐藏顶部和底部导航，多列布局 |
| 大屏幕 | ≥ 1600px | 固定主内容宽度为 1400px |

### 9.2 布局调整

- 主内容区域：
  - 移动端：margin-left: 0, margin-top: 64px, padding: 16px
  - 平板端：margin-left: 0, margin-top: 64px, padding: 24px
  - 桌面端：margin-left: 200px, margin-top: 0, padding: 32px

- 统计卡片：
  - 移动端：单列布局
  - 平板端：双列布局
  - 桌面端：三列布局

- 按钮组：
  - 移动端：垂直排列
  - 桌面端：水平排列

## 10. 设计系统使用指南

### 10.1 CSS变量

设计系统采用CSS变量实现样式的统一管理，变量名遵循以下命名规范：

- 颜色：--color-名称
- 字体：--font-名称
- 间距：--spacing-名称
- 圆角：--radius-名称
- 阴影：--shadow-名称

### 10.2 组件使用

- 遵循组件设计规范，保持样式一致性
- 优先使用设计系统提供的组件
- 自定义组件时，参考设计系统的样式规范

### 10.3 交互设计

- 遵循交互设计规范，提供一致的交互体验
- 确保交互反馈清晰明确
- 优化操作流程，减少用户操作步骤

## 11. 设计系统维护

- 定期更新设计系统文档，保持与代码同步
- 新增组件时，更新设计系统规范
- 样式变更时，同步更新设计系统文档
- 定期审查设计系统，确保设计一致性
