# 天堂股东体验卡PRD功能说明书

## 1. 项目概述

天堂股东体验卡是一款为酒吧/夜店核心股东与会员打造的一站式会员管理与订台系统。支持Web端与微信小程序双端访问，提供可视化订台、会员周期管理、订单追踪与返现结算等核心功能。

### 1.1 项目定位
- **目标用户**：酒吧/夜店核心股东、VIP会员
- **核心价值**：为核心用户提供便捷的订台体验和权益管理，提升用户粘性和运营效率
- **双端支持**：Web端（Next.js）和微信小程序原生开发

### 2.2 模块间逻辑关系

1. **认证与权限管理**是所有功能的基础，用户必须登录才能访问其他功能
2. **会员服务**为订台和订单管理提供用户身份和权益支持
3. **订台服务**生成预订信息，驱动订单管理和支付服务
4. **订单管理**关联订台信息和支付记录，处理返现结算
5. **支付服务**为订单提供支付支持，更新订单状态
6. **管理员后台**管理系统全局配置和所有业务数据

## 3. 已实现功能详述

### 3.1 认证与权限管理

#### 3.1.1 页面分布
- **登录页**：`/login` - 提供手机号和密码登录功能
- **注册页**：`/register` - 提供用户注册功能

#### 3.1.2 用户旅程
1. **注册流程**：
   - 用户访问注册页，输入手机号、密码等信息
   - 提交注册信息，系统验证数据合法性
   - 注册成功后跳转至登录页，提示等待管理员开通

2. **登录流程**：
   - 用户访问登录页，输入手机号和密码
   - 点击登录按钮，系统验证身份信息
   - 验证成功后跳转至订台页面
   - 验证失败则显示错误信息

#### 3.1.3 数据处理逻辑
- **身份验证**：使用JWT + Refresh Token机制
- **密码加密**：采用bcryptjs进行密码哈希存储
- **权限控制**：基于用户角色（admin/member）进行权限管理
- **会话管理**：使用Next.js API Routes和Cookie进行会话管理

### 3.2 会员服务

#### 3.2.1 页面分布
- **会员中心**：`/memberships` - 展示会员信息、会员周期、钱包余额等

#### 3.2.2 用户旅程
1. **查看会员信息**：
   - 用户登录后点击导航栏"我的"进入会员中心
   - 系统展示当前会员信息、会员有效期、钱包余额等
   - 用户可以查看返现记录和消费历史

#### 3.2.3 数据处理逻辑
- **会员周期管理**：支持月卡、季卡等多种会员套餐
- **钱包管理**：记录用户余额、返现收入、消费支出等
- **返现计算**：根据消费金额和返现比例自动计算返现金额
- **数据获取**：通过API从数据库获取会员信息和钱包数据

### 3.3 订台服务

#### 3.3.1 页面分布
- **订台页面**：`/bookings` - 提供可视化座位图和订台功能

#### 3.3.2 用户旅程
1. **订台流程**：
   - 用户登录后进入订台页面
   - 系统展示可视化座位图，显示不同区域（A/B/M）的酒台状态
   - 用户选择可用酒台，填写预订信息
   - 提交预订请求，系统生成预订记录
   - 预订成功后跳转至订单详情页

#### 3.3.3 数据处理逻辑
- **座位图数据**：从数据库获取酒台信息和状态
- **预订验证**：检查酒台是否可用，验证用户权限
- **预订生成**：创建预订记录，更新酒台状态
- **实时同步**：支持座位图实时更新，避免重复预订

### 3.4 订单管理

#### 3.4.1 页面分布
- **订单查询**：集成在会员中心页面，提供订单历史查询
- **管理员订单管理**：`/admin/orders` - 管理员查看所有订单

#### 3.4.2 用户旅程
1. **用户查看订单**：
   - 用户进入会员中心，查看订单历史
   - 可以筛选和搜索订单，查看订单详情
   - 查看订单状态和返现情况

2. **管理员管理订单**：
   - 管理员登录后进入订单管理页面
   - 查看所有订单列表，支持筛选和搜索
   - 查看订单详情，处理订单异常
   - 管理返现结算

#### 3.4.3 数据处理逻辑
- **订单生成**：订台成功后自动生成订单
- **订单状态**：支持待支付、已支付、已完成、已取消等状态
- **返现结算**：根据消费金额和返现比例自动计算返现
- **数据存储**：所有订单数据存储在数据库中，支持历史查询

### 3.5 支付服务

#### 3.5.1 页面分布
- **支付页面**：集成在订台流程中，跳转至支付网关
- **支付结果页**：支付成功或失败后返回的结果页面

#### 3.5.2 用户旅程
1. **支付流程**：
   - 用户完成订台后，选择支付方式（微信/支付宝）
   - 系统生成支付链接，跳转至支付网关
   - 用户完成支付，支付网关回调通知系统
   - 系统更新订单状态，完成返现计算
   - 用户返回系统，查看支付结果

#### 3.5.3 数据处理逻辑
- **支付集成**：支持微信支付（Native/H5/JSAPI）和支付宝支付
- **支付回调**：异步处理支付结果，更新订单状态
- **支付验证**：验证支付签名，确保支付安全性
- **状态同步**：实时同步支付状态和订单状态

### 3.6 管理员后台

#### 3.6.1 页面分布
- **管理员首页**：`/admin` - 管理员仪表盘
- **座位图管理**：集成在管理员后台，提供可视化编辑功能
- **订单管理**：`/admin/orders` - 管理所有订单
- **会员管理**：`/admin/accounts` - 管理所有会员账户

#### 3.6.2 用户旅程
1. **管理员登录**：
   - 管理员使用管理员账号登录系统
   - 进入管理员后台首页

2. **管理座位图**：
   - 管理员进入座位图管理页面
   - 可视化编辑座位图，调整酒台位置和状态
   - 保存座位图，系统实时更新

3. **管理预订和订单**：
   - 管理员查看所有预订和订单
   - 处理预订请求，管理订单状态
   - 处理返现结算

4. **管理会员**：
   - 管理员查看所有会员信息
   - 开通/禁用会员账号
   - 更新会员信息和权益

#### 3.6.3 数据处理逻辑
- **管理员权限**：最高权限，可访问所有功能
- **座位图编辑**：支持拖拽调整酒台位置，实时保存
- **数据管理**：支持批量操作和数据导出
- **系统配置**：管理全局参数和返现比例

### 5.2 页面风格

- **玻璃态设计**：部分组件采用半透明玻璃态效果，增强视觉质感

| 颜色类型 | 颜色值 | 用途 |

### 6.2 核心业务逻辑

#### 6.2.1 会员周期管理
- **会员类型**：支持月卡、季卡等多种会员套餐
- **有效期计算**：从开通日期起按自然月计算
- **到期提醒**：到期前自动提醒用户
- **权益关联**：不同会员等级享受不同权益（如订台优先级、返现比例等）

#### 6.2.2 返现计算逻辑
- **返现比例**：根据会员等级和酒台区域设置不同返现比例
- **返现触发**：订单完成后自动计算返现
- **返现到账**：返现金额直接进入用户钱包
- **返现限制**：可设置最低消费金额和返现上限

#### 6.2.3 订台逻辑
- **酒台状态**：支持可用、已预订、已占用、维护中等状态
- **预订规则**：可设置预订提前时间、预订保留时长等
- **冲突检测**：实时检测酒台预订冲突，避免重复预订
- **预订确认**：支持自动确认和人工确认两种模式

### 6.3 安全机制

1. **数据安全**：
   - 密码加密存储（bcryptjs）
   - 敏感数据传输加密（HTTPS）
   - 数据库查询参数化，防止SQL注入

2. **认证安全**：
   - JWT Token 有效期限制
   - Refresh Token 机制
   - 登录失败次数限制
   - 安全的Cookie配置（HttpOnly, Secure, SameSite）

3. **权限控制**：
   - 基于角色的权限管理
   - API路由权限验证
   - 页面访问权限控制

4. **支付安全**：
   - 支付签名验证
   - 支付回调IP白名单
   - 支付金额一致性校验
